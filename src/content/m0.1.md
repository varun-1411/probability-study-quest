## How to read this module

This module is the grammar for everything that follows. None of it is hard, but every later proof is written in this language, so a gap here becomes confusion in Module 1.2. Read slowly.

Each section has the same shape:

- **the idea** in plain words, and why probability needs it;
- **the precise definition**;
- **worked examples**, most of them at the taxi stand;
- **common mistakes**;
- **quick checks** with answers. Cover the answer, try the question, then look.

Time budget: about 12 hours over the two scheduled weeks. Spend roughly 5 hours on these notes and the book sections, 5 on the problem set and 2 on the code lab and review.

## The story

At the airport taxi stand, all sorts of things happen that we want to talk about precisely:

- "at least five taxis were waiting at 6 pm";
- "the passenger queue emptied before 7 pm";
- "a taxi was turned away because the buffer was full";
- "on infinitely many days the buffer emptied at least once".

Each of these is an **event**: something that, on any given day, either happened or did not. Probability will attach a number to each event. Before it can, four things must be in place.

1. **A way to combine statements**: and, or, not, and their infinite versions, "on some day", "on every day", "infinitely often", "from some day on". That is logic and set theory (Sections 1–3).
2. **A way to describe random quantities.** The number of waiting taxis at 6 pm is not a single number. It is a different number on each day. A quantity that depends on the outcome is a **function** of the outcome (Section 4).
3. **A way to group outcomes that look the same to us**, for example all days with the same queue length (Section 5).
4. **A way to count infinitely many outcomes.** Probability can add up a sequence of pieces, but not more than that, so we need to know which sets can be listed as a sequence (Section 6).

In one line: **sets are events, functions are random variables, preimages turn questions about random variables into events, and countability explains why probability adds only over countable lists.**

Why this much precision? Because intuition built on finitely many outcomes breaks down with infinitely many. Toss a fair coin forever. Every particular sequence of heads and tails has probability $0$, yet some sequence certainly occurs. With finite thinking that looks like a paradox. With the tools of this module it is a simple fact (Section 6.6).

## The picture

Draw these four before you read on. You will use them all year.

2. Two blobs $X$ and $Y$ with arrows from points of $X$ to points of $Y$: a function. Circle a set $B\subseteq Y$. Then circle everything in $X$ whose arrow lands in $B$. That circled set is the **preimage** $f^{-1}(B)$, and it is the most important object in this module.
3. A grid of dots $(m,n)$ with a zig-zag path through them, along the diagonals $m+n=2,3,4,\dots$: the reason $\mathbb N\times\mathbb N$ can be listed as a sequence.
4. A row of boxes for days $1,2,3,\dots$, with a tick in day $n$'s box when event $A_n$ happens. Draw three rows: ticks that stop after a while; ticks that never stop but keep having gaps; ticks that, from some day on, never miss. These three rows are "finitely often", "infinitely often" and "eventually always" (Section 3.7).

## 1. Logic: the grammar of proofs

### 1.1 Statements and connectives

A **statement** is a sentence that is either true or false: "the buffer holds 10 taxis", "7 is prime", "$2+2=5$". A sentence such as "$x>3$" is not a statement until we know $x$; it is a **predicate** $P(x)$, which becomes a statement once $x$ is fixed.

Statements combine with five connectives:

| Symbol | Read as | True when |
|---|---|---|
| $P\wedge Q$ | $P$ and $Q$ | both are true |
| $P\vee Q$ | $P$ or $Q$ | at least one is true |
| $\neg P$ | not $P$ | $P$ is false |
| $P\Rightarrow Q$ | if $P$ then $Q$ | see below |
| $P\Leftrightarrow Q$ | $P$ if and only if $Q$ | both true or both false |

The full truth table:

| $P$ | $Q$ | $P\wedge Q$ | $P\vee Q$ | $P\Rightarrow Q$ | $P\Leftrightarrow Q$ |
|---|---|---|---|---|---|
| T | T | T | T | T | T |
| T | F | F | T | F | F |
| F | T | F | T | T | F |
| F | F | F | F | T | T |

In mathematics, "or" is always **inclusive**: "$P$ or $Q$" allows both. When we mean "exactly one", we say so.

### 1.2 Implication, the connective that matters most

Read $P\Rightarrow Q$ as a **promise**: "if the buffer is full, then an arriving taxi is turned away." The promise is broken in exactly one situation: the buffer is full and the arriving taxi is *not* turned away. On a day when the buffer is not full, the promise says nothing, so it has not been broken, and we count it as true. That is why the last two rows of the table say T: **when the hypothesis is false, the implication is true.** Such an implication is called *vacuously true*. "If $2+2=5$, then the moon is made of cheese" is a true statement.

Many phrases mean $P\Rightarrow Q$: "if $P$ then $Q$", "$P$ implies $Q$", "$Q$ whenever $P$", "$P$ only if $Q$", "$P$ is sufficient for $Q$", "$Q$ is necessary for $P$". The phrase "$P$ only if $Q$" trips people up; read it as "$P$ cannot happen without $Q$".

Three relatives of $P\Rightarrow Q$:

- **Contrapositive** $\neg Q\Rightarrow\neg P$: "if the arriving taxi was not turned away, the buffer was not full." It has exactly the same truth table as $P\Rightarrow Q$ (check the four rows). So proving the contrapositive proves the original.
- **Converse** $Q\Rightarrow P$: "if a taxi was turned away, the buffer was full." This is a *different* statement. Here it happens to be true too, but in general it is not. "If a sequence converges, it is bounded" is true; its converse "if a sequence is bounded, it converges" is false, as $1,-1,1,-1,\dots$ shows.
- **Negation** $\neg(P\Rightarrow Q)$, which is equivalent to $P\wedge\neg Q$: "the buffer was full **and** the taxi was not turned away." A common mistake is to write the negation as $P\Rightarrow\neg Q$. It is not an implication at all; it is a claim that a counterexample exists.

$P\Leftrightarrow Q$ means $(P\Rightarrow Q)\wedge(Q\Rightarrow P)$. To prove an "if and only if", prove two implications, one in each direction.

### 1.3 Quantifiers

Two symbols turn predicates into statements:

- $\forall x\in S\;P(x)$: "for every $x$ in $S$, $P(x)$ holds";
- $\exists x\in S\;P(x)$: "there is at least one $x$ in $S$ with $P(x)$".

At the stand, with $S$ the set of today's taxis and $W(t)$ meaning "taxi $t$ waited more than 10 minutes": $\forall t\;W(t)$ says every taxi waited long; $\exists t\;W(t)$ says at least one did.

**Negating quantifiers.** "Not every taxi waited long" means "some taxi did not wait long". "No taxi waited long" (not: there exists one that did) means "every taxi waited at most 10 minutes". In symbols:
$$\neg\big(\forall x\;P(x)\big)\iff\exists x\;\neg P(x),\qquad\neg\big(\exists x\;P(x)\big)\iff\forall x\;\neg P(x).$$
The domain stays the same: the negation of $\forall x\in S\,P(x)$ is $\exists x\in S\,\neg P(x)$. To negate a statement with several quantifiers, walk from left to right, flipping each quantifier, and negate the condition at the end. Nothing else changes.

*Worked example.* "$x_n$ converges to $x$" is
$$\forall\varepsilon>0\;\;\exists N\;\;\forall n\ge N\;\;|x_n-x|<\varepsilon .$$
Negate step by step:
$$\exists\varepsilon>0\;\;\neg\big(\exists N\;\forall n\ge N\;|x_n-x|<\varepsilon\big)$$
$$\exists\varepsilon>0\;\;\forall N\;\;\neg\big(\forall n\ge N\;|x_n-x|<\varepsilon\big)$$
$$\exists\varepsilon>0\;\;\forall N\;\;\exists n\ge N\;\;|x_n-x|\ge\varepsilon .$$
In words: there is a fixed tolerance that the sequence violates again and again, however far out you go.

**Order matters.** Compare

- $\forall h\;\exists t\;W(t,h)$: "for every hour $h$ there is a taxi $t$ that waits long in that hour", and
- $\exists t\;\forall h\;W(t,h)$: "there is one taxi $t$ that waits long in every hour".

In the first, the taxi may change from hour to hour; in the second, one taxi must do it all day. The second implies the first, but not the other way round. A purely mathematical example: $\forall x\in\mathbb R\;\exists y\in\mathbb R\;y>x$ is true (take $y=x+1$), while $\exists y\;\forall x\;y>x$ says some real number is larger than every real number, including itself, which is false.

**Quantifiers as a game.** A useful way to read a nested statement: $\forall$ is your opponent's move and $\exists$ is yours. The statement is true when you have a winning strategy. For convergence, the opponent names a tolerance $\varepsilon$; you answer with an index $N$, which may depend on $\varepsilon$; the opponent picks any $n\ge N$; you win if $|x_n-x|<\varepsilon$. "The sequence converges" means you can always win. "It does not converge" means the opponent can always win: they have a bad $\varepsilon$, and whatever $N$ you choose they find an $n\ge N$ beyond tolerance. Module 0.2 is full of statements like this.

**Vacuous truth for quantifiers.** "$\forall x\in\varnothing\;P(x)$" is true whatever $P$ is, because there is no $x$ that could fail. This is why the empty set is a subset of every set (Section 3.1).

**Quick checks.**

1. Negate "every hour, some taxi waits more than 10 minutes".
2. Is "if $2+2=5$ then $1=0$" true?
3. Write the contrapositive and the converse of "if a sequence converges, then it is bounded". Which one is equivalent to the original?

*Answers.* (1) There is an hour in which every taxi waits at most 10 minutes. (2) Yes, vacuously: the hypothesis is false. (3) Contrapositive: "if a sequence is unbounded, it does not converge", equivalent to the original. Converse: "if a sequence is bounded, it converges", which is false.

## 2. How to write a proof

A **proof** is an argument that a skeptical reader can check line by line. Every line follows from definitions, from earlier lines, or from results already proved. The most useful skill is recognising the **shape** of the claim, because the shape tells you how the proof starts and how it ends.

| To prove | Start by writing | You are done when you show |
|---|---|---|
| $P\Rightarrow Q$ (direct) | Assume $P$. | $Q$ |
| $P\Rightarrow Q$ (contrapositive) | Assume $\neg Q$. | $\neg P$ |
| $P$ (by contradiction) | Suppose $\neg P$. | something false |
| $\forall x\in S\;P(x)$ | Let $x\in S$ be arbitrary. | $P(x)$ for that $x$ |
| $\exists x\;P(x)$ | (Find a candidate $x$.) | that the candidate works |
| $P\Leftrightarrow Q$ | Prove $P\Rightarrow Q$, then $Q\Rightarrow P$. | both directions |
| $A\subseteq B$ | Let $x\in A$. | $x\in B$ |
| $A=B$ | Prove $A\subseteq B$, then $B\subseteq A$. | both inclusions |
| $f$ injective | Suppose $f(x)=f(x')$. | $x=x'$ |
| $f$ surjective | Let $y\in Y$. | some $x$ with $f(x)=y$ |
| $P(n)$ for all $n\ge1$ | Induction: prove $P(1)$, then $P(n)\Rightarrow P(n+1)$. | both steps |
| "$\forall x\;P(x)$" is false | (Find one $x$.) | $\neg P(x)$ for it |

The first move in almost every proof is to **unpack the definitions**: write out what each word in the claim means. Most short proofs are little more than that.

### 2.1 Direct proof

*Claim.* If $n$ is odd, then $n^2$ is odd.

*Plan.* Assume $n$ is odd, unpack "odd", compute, repack.

*Proof.* Since $n$ is odd, $n=2k+1$ for some integer $k$. Then $n^2=4k^2+4k+1=2(2k^2+2k)+1$. As $2k^2+2k$ is an integer, $n^2$ has the form $2(\text{integer})+1$, so it is odd. $\blacksquare$

*Claim.* If $A\subseteq B$ and $B\subseteq C$, then $A\subseteq C$.

*Proof.* Let $x\in A$. Since $A\subseteq B$, $x\in B$. Since $B\subseteq C$, $x\in C$. As $x$ was an arbitrary element of $A$, $A\subseteq C$. $\blacksquare$

Notice the phrase "as $x$ was arbitrary". We proved the statement for one $x$ about which we assumed nothing except $x\in A$, so the argument works for every element of $A$. That is how every "for all" statement is proved.

### 2.2 Proof by contrapositive

*Claim.* If $n^2$ is even, then $n$ is even.

A direct attempt stalls: from $n^2=2k$ you would want $n=\sqrt{2k}$, and nothing useful follows. The contrapositive is "if $n$ is odd, then $n^2$ is odd", which is exactly the claim we proved in 2.1. Since a statement and its contrapositive are equivalent, we are done. **Use the contrapositive when the negated conclusion gives you something concrete to work with.**

### 2.3 Proof by contradiction

*Claim.* $\sqrt2$ is irrational.

*Plan.* Suppose it is rational and derive something impossible.

*Proof.* Suppose $\sqrt2=p/q$ with integers $p,q$, $q\ne0$. Every fraction can be reduced to lowest terms, so we may assume $p$ and $q$ have no common factor. Squaring, $p^2=2q^2$, so $p^2$ is even, and by 2.2, $p$ is even: $p=2r$. Then $4r^2=2q^2$, so $q^2=2r^2$ is even, and $q$ is even too. Now $2$ divides both $p$ and $q$, contradicting lowest terms. So $\sqrt2$ is not rational. $\blacksquare$

Contradiction and contrapositive are different. A proof by contrapositive proves $\neg Q\Rightarrow\neg P$ and is a direct proof of that statement. A proof by contradiction assumes the whole claim is false and runs until something breaks.

### 2.4 Proof by cases

When different situations need different arguments, split into cases that cover everything.

*Claim.* For every integer $n$, $n^2+n$ is even.

*Proof.* Every integer is even or odd. If $n=2k$, then $n^2+n=2k(2k+1)$, which is even. If $n=2k+1$, then $n^2+n=(2k+1)(2k+2)=2(2k+1)(k+1)$, which is even. $\blacksquare$

At the stand you will split by the sign of a state variable: whether taxis or passengers are waiting (Problem T1).

### 2.5 Induction

To prove $P(n)$ for every $n\ge1$:

1. **Base case:** prove $P(1)$.
2. **Inductive step:** let $n\ge1$, assume $P(n)$ (the *induction hypothesis*), and prove $P(n+1)$.

*Why it works.* Suppose both steps hold but $P$ fails somewhere. Every nonempty set of positive integers has a smallest element, so there is a smallest $m$ with $P(m)$ false. $m\ne1$ by the base case, so $m-1\ge1$, and $P(m-1)$ is true because $m$ was the smallest failure. The inductive step then gives $P(m)$, a contradiction.

*Claim.* $1+2+\dots+n=\dfrac{n(n+1)}{2}$ for every $n\ge1$.

*Proof.* Base case: $1=\frac{1\cdot2}{2}$. Inductive step: assume $1+\dots+n=\frac{n(n+1)}2$. Then
$$1+\dots+n+(n+1)=\frac{n(n+1)}2+(n+1)=\frac{(n+1)(n+2)}2,$$
which is the formula for $n+1$. $\blacksquare$

**Strong induction** assumes $P(1),\dots,P(n)$ all hold in the step, not just $P(n)$. *Example:* every integer $n\ge2$ is a product of primes. If $n$ is prime, it is a product of one prime. Otherwise $n=ab$ with $2\le a,b<n$, and by the strong hypothesis $a$ and $b$ are both products of primes, so $n$ is too.

**A classic broken induction.** "All horses in any group of $n$ horses have the same colour." Base case $n=1$: true. "Step": from a group of $n+1$ horses, remove the first; the remaining $n$ share a colour. Remove the last instead; those $n$ share a colour. The two groups overlap, so all $n+1$ share a colour. The flaw: going from $n=1$ to $n=2$, the two groups are $\{h_2\}$ and $\{h_1\}$, which do **not** overlap. An inductive step must work for every $n\ge1$, including the smallest.

You will use induction to go from two sets to $n$ sets, for example from $|A\cup B|\le|A|+|B|$ to the union bound (Problem B5).

### 2.6 Counterexamples

To show that a "for all" claim is false, one example is enough, as long as it is concrete and you check it. "Every function satisfies $f(A\cap B)=f(A)\cap f(B)$" fails for $f(x)=x^2$, $A=[-1,0]$, $B=[0,1]$ (Problem A5). "Every bounded sequence converges" fails for $1,-1,1,-1,\dots$

### 2.7 Writing proofs that others can read

- Say what you are proving and which method you are using.
- Introduce every symbol before you use it ("Let $x\in A$").
- One claim per sentence, each with its reason.
- End by stating that you reached what you wanted.

**Quick checks.**

1. Write the first and last lines of a proof that $f(x)=2x+1$ is injective on $\mathbb R$, then fill in the middle.
2. Which method suits "there is no largest integer"?

*Answers.* (1) "Suppose $f(x)=f(x')$." Then $2x+1=2x'+1$, so $2x=2x'$ and "$x=x'$". (2) Contradiction: if $N$ were the largest integer, $N+1$ would be a larger one.

## 3. Sets are events

### 3.1 Sets, elements and subsets

A **set** is a collection of objects, its **elements**; $x\in A$ means $x$ is an element of $A$. You can describe a set by listing it, $\{1,2,3\}$, or by a rule, $\{x\in\mathbb R:x^2<2\}$, read "the set of real $x$ such that $x^2<2$". Order and repetition do not matter: $\{1,2,2\}=\{2,1\}$.

Standard sets: the empty set $\varnothing$; $\mathbb N=\{1,2,3,\dots\}$ (in this course $\mathbb N$ starts at $1$); the integers $\mathbb Z$; the rationals $\mathbb Q$; the reals $\mathbb R$; intervals such as $[a,b]$, $(a,b]$ and $[a,\infty)$.

**Subsets.** $A\subseteq B$ means every element of $A$ is an element of $B$. Two sets are **equal** when they have the same elements, which is the same as $A\subseteq B$ and $B\subseteq A$. That is how almost every set equality is proved: by **double inclusion**. The empty set is a subset of every set, vacuously: it has no element that could fail to be in $B$.

*Common mistake:* confusing $\in$ and $\subseteq$. $1\in\{1,2\}$ and $\{1\}\subseteq\{1,2\}$, but $\{1\}\notin\{1,2\}$: the set $\{1,2\}$ has elements $1$ and $2$, not the set $\{1\}$.

Two constructions you will meet constantly:

- The **power set** $2^X$ is the set of all subsets of $X$. If $X$ has $n$ elements, $2^X$ has $2^n$, since each element is either in or out of a subset. The events of a finite model are exactly $2^\Omega$.
- The **Cartesian product** $X\times Y=\{(x,y):x\in X,\ y\in Y\}$ is the set of ordered pairs. The state of the stand, (taxis waiting, passengers waiting), is a point of a product set.

### 3.2 The sample space

The first modelling step in every probability problem is to choose the **sample space** $\Omega$: the set of all outcomes, where each outcome is one complete description of what could happen. Examples:

- One roll of a die: $\Omega=\{1,2,3,4,5,6\}$.
- The number of taxis waiting at 6 pm with a buffer of $10$: $\Omega=\{0,1,\dots,10\}$.
- A whole day at the stand: $\Omega$ is the set of all possible lists of taxi and passenger arrival times. It is infinite, and each outcome is a long record.
- A coin tossed forever: $\Omega=\{0,1\}^{\mathbb N}$, the set of all infinite $0$–$1$ sequences.

Choosing $\Omega$ is a modelling decision. A richer $\Omega$ lets you ask more questions: with the day-long $\Omega$ you can ask about the queue at any time, while with $\{0,\dots,10\}$ you can only ask about 6 pm. An **event** is a subset of $\Omega$, the set of outcomes on which the event happens. (For uncountable $\Omega$ it will turn out that not every subset can be an event; Module 1.2 explains why. For this module, every subset is.)

### 3.3 The dictionary between sets and events

| Set language | Event language |
|---|---|
| $\omega\in A$ | $A$ happened on outcome $\omega$ |
| $A\cup B$ | $A$ or $B$ (or both) |
| $A\cap B$ | $A$ and $B$ |
| $A^c=\Omega\setminus A$ | $A$ did not happen |
| $A\setminus B=A\cap B^c$ | $A$ but not $B$ |
| $A\triangle B=(A\setminus B)\cup(B\setminus A)$ | exactly one of $A$, $B$ |
| $A\subseteq B$ | whenever $A$ happens, $B$ happens |
| $A\cap B=\varnothing$ | $A$ and $B$ cannot both happen |
| $\Omega$ | the certain event |
| $\varnothing$ | the impossible event |

*Worked example.* Let $\Omega$ be the set of possible days, $A$ = "at least five taxis wait at 6 pm" and $B$ = "the passenger queue empties before 7 pm". Then:

- $A\cap B^c$: at least five taxis wait at 6 pm, yet the queue does not empty before 7 pm. Surprising, and worth investigating if it ever happens: are taxis waiting at the wrong terminal?
- $A^c\cup B$: fewer than five taxis wait at 6 pm, or the queue empties before 7 pm.
- $(A\cap B^c)^c=A^c\cup B$: the two lines above are complements of each other, an instance of De Morgan's law below.

Events $A_1,\dots,A_m$ are **disjoint** (mutually exclusive) if no two can happen together, $A_i\cap A_j=\varnothing$ for $i\ne j$. A **partition** of $\Omega$ is a family of disjoint events whose union is $\Omega$: on every outcome, exactly one of them happens. The events "exactly $k$ taxis wait at 6 pm", $k=0,1,\dots,10$, partition $\Omega$.

### 3.4 Laws of set algebra

Union and intersection are commutative and associative, and each distributes over the other:
$$A\cap(B\cup C)=(A\cap B)\cup(A\cap C),\qquad A\cup(B\cap C)=(A\cup B)\cap(A\cup C).$$

*Proof of the first, by double inclusion.* ($\subseteq$) Let $\omega\in A\cap(B\cup C)$. Then $\omega\in A$, and $\omega\in B$ or $\omega\in C$. If $\omega\in B$, then $\omega\in A\cap B$; if $\omega\in C$, then $\omega\in A\cap C$. Either way $\omega\in(A\cap B)\cup(A\cap C)$. ($\supseteq$) Let $\omega\in(A\cap B)\cup(A\cap C)$. In either case $\omega\in A$, and $\omega$ is in $B$ or in $C$, so $\omega\in A\cap(B\cup C)$. $\blacksquare$

Once you are fluent, you can write the same proof as one chain of equivalences, each step a law of logic:
$$\omega\in A\cap(B\cup C)\iff\omega\in A\wedge(\omega\in B\vee\omega\in C)\iff(\omega\in A\wedge\omega\in B)\vee(\omega\in A\wedge\omega\in C)\iff\omega\in(A\cap B)\cup(A\cap C).$$

**De Morgan's laws.** $(A\cup B)^c=A^c\cap B^c$ and $(A\cap B)^c=A^c\cup B^c$. In words: "not ($A$ or $B$)" is "not $A$ and not $B$", and "not ($A$ and $B$)" is "not $A$ or not $B$". The proof is a chain:
$$\omega\in(A\cup B)^c\iff\omega\notin A\cup B\iff(\omega\notin A\text{ and }\omega\notin B)\iff\omega\in A^c\cap B^c .$$

*Common mistake:* $(A\cap B)^c=A^c\cap B^c$. Test it on the stand: "not (rain and strike)" is not "no rain and no strike"; a day with rain and no strike is in the first set but not in the second. Complementing swaps $\cap$ and $\cup$.

### 3.5 Infinite unions and intersections

Probability talks about infinitely many events at once: "on some day", "at every time". For any family of sets $(A_i)_{i\in I}$, with $I$ finite or infinite,
$$\omega\in\bigcup_{i\in I}A_i\iff\exists i\in I:\ \omega\in A_i,\qquad\omega\in\bigcap_{i\in I}A_i\iff\forall i\in I:\ \omega\in A_i .$$
So an infinite union is an infinite "or", and an infinite intersection is an infinite "and". The quantifiers of Section 1 are exactly the tool for working with them. De Morgan's laws hold for any family, with the same proof (Problem B1):
$$\Big(\bigcup_{i\in I}A_i\Big)^c=\bigcap_{i\in I}A_i^c,\qquad\Big(\bigcap_{i\in I}A_i\Big)^c=\bigcup_{i\in I}A_i^c .$$

*Worked examples.* Each is proved by double inclusion, using the fact that for every $x>0$ there is an $n$ with $1/n<x$ (the Archimedean property, proved in Module 0.2).

1. $\bigcup_{n\ge1}[1/n,1]=(0,1]$. Each $[1/n,1]\subseteq(0,1]$, so the union is inside $(0,1]$. Conversely, if $0<x\le1$, choose $n$ with $1/n<x$; then $x\in[1/n,1]$. The point $0$ is never captured, so a union of closed intervals can fail to be closed.
2. $\bigcap_{n\ge1}(0,1/n)=\varnothing$. If $x\le0$, $x$ is in none of the sets. If $x>0$, choose $n$ with $1/n<x$; then $x\notin(0,1/n)$. Each set is nonempty, they shrink, and nothing survives.
3. $\bigcap_{n\ge1}[0,1/n]=\{0\}$. The point $0$ is in every set; any $x>0$ drops out once $1/n<x$.
4. $\bigcap_{n\ge1}(-1/n,\,1+1/n)=[0,1]$. Points of $[0,1]$ are in every set; a point $x>1$ drops out once $1/n<x-1$, and similarly for $x<0$. Open sets can intersect down to a closed one.

The lesson is that limits of sets produce new kinds of sets, and you have to check endpoints by hand.

*At the stand.* Let $Q_t$ be the passenger queue at time $t$, and $F_n$ the event "the buffer is full at some moment on day $n$". Then "the buffer is full on some day" is $\bigcup_nF_n$ and "it is full on every day" is $\bigcap_nF_n$. The event "the queue ever exceeds 20 today" is $\bigcup_{t}\{Q_t>20\}$, a union over **uncountably** many times. That will matter, because probability can only handle countable unions directly (Section 6.6). The usual rescue: the queue only changes by jumps and stays constant for a while after each jump (its paths are right-continuous). So if $Q_t>20$ at some time $t$, it is still above 20 at some rational time just after $t$. Hence the event equals $\bigcup_{t\in\mathbb Q,\,t\ge0}\{Q_t>20\}$, a countable union. Module 3.3 uses this trick.

**Monotone sequences.** If $A_1\subseteq A_2\subseteq\cdots$ (an increasing sequence of events, such as "the queue has exceeded 20 by time $n$"), the natural limit is $\bigcup_nA_n$. If $A_1\supseteq A_2\supseteq\cdots$, it is $\bigcap_nA_n$. Module 1.2 proves that probability is continuous along such sequences.

### 3.6 Indicator functions

The **indicator** of an event $A$ is the function
$$\mathbf 1_A(\omega)=\begin{cases}1&\omega\in A,\\0&\omega\notin A.\end{cases}$$
It turns set algebra into ordinary algebra. The rules:
$$\mathbf 1_{A\cap B}=\mathbf 1_A\mathbf 1_B,\qquad\mathbf 1_{A^c}=1-\mathbf 1_A,\qquad\mathbf 1_{A\cup B}=\mathbf 1_A+\mathbf 1_B-\mathbf 1_A\mathbf 1_B,\qquad A\subseteq B\iff\mathbf 1_A\le\mathbf 1_B .$$

*Proof by cases.* An outcome $\omega$ lies in one of four regions of the picture. Check each rule in each region:

| Where $\omega$ is | $\mathbf 1_A$ | $\mathbf 1_B$ | $\mathbf 1_A\mathbf 1_B$ | $\mathbf 1_A+\mathbf 1_B-\mathbf 1_A\mathbf 1_B$ | $\mathbf 1_{A\cap B}$ | $\mathbf 1_{A\cup B}$ |
|---|---|---|---|---|---|---|
| in both | 1 | 1 | 1 | 1 | 1 | 1 |
| in $A$ only | 1 | 0 | 0 | 1 | 0 | 1 |
| in $B$ only | 0 | 1 | 0 | 1 | 0 | 1 |
| in neither | 0 | 0 | 0 | 0 | 0 | 0 |

The columns agree in every row, so the identities hold for every $\omega$.

**Inclusion–exclusion for free.** By De Morgan, $\mathbf 1_{A\cup B\cup C}=1-\mathbf 1_{A^c\cap B^c\cap C^c}=1-(1-\mathbf 1_A)(1-\mathbf 1_B)(1-\mathbf 1_C)$. Expanding the product,
$$\mathbf 1_{A\cup B\cup C}=\mathbf 1_A+\mathbf 1_B+\mathbf 1_C-\mathbf 1_A\mathbf 1_B-\mathbf 1_A\mathbf 1_C-\mathbf 1_B\mathbf 1_C+\mathbf 1_A\mathbf 1_B\mathbf 1_C .$$
Once expectation is defined, $E[\mathbf 1_A]=P(A)$, and this line becomes the inclusion–exclusion formula $P(A\cup B\cup C)=P(A)+P(B)+P(C)-P(A\cap B)-\dots$ with no extra work.

**Indicators count.** If $A_1,\dots,A_m$ are events, $N=\mathbf 1_{A_1}+\dots+\mathbf 1_{A_m}$ is the number of them that happen. With three terminals and $A_i$ = "a taxi waits at terminal $i$", $N$ is the number of terminals with a taxi (Problem C1). Later, $E[N]=P(A_1)+\dots+P(A_m)$, even when the events are dependent. That one line solves many counting problems.

### 3.7 Infinitely often and eventually: limsup and liminf of events

Long-run questions at the stand sound like this: does the buffer empty on infinitely many days? Does blocking eventually stop for good? To write them as events, fix a sequence of events $A_1,A_2,\dots$, say $A_n$ = "the buffer empties on day $n$", and picture 4 above: for a fixed outcome $\omega$, a row of boxes with a tick on day $n$ when $\omega\in A_n$.

Build the two events in two steps.

- Let $T_n=\bigcup_{k\ge n}A_k$: "$A$ happens on day $n$ or later". Then $\omega\in T_n$ **for every** $n$ exactly when the ticks never stop. So
$$\limsup_nA_n=\bigcap_{n\ge1}\bigcup_{k\ge n}A_k=\{\omega:\ \omega\in A_n\text{ for infinitely many }n\}.$$
- Let $S_n=\bigcap_{k\ge n}A_k$: "$A$ happens on every day from day $n$ on". Then $\omega\in S_n$ **for some** $n$ exactly when, after some day, there are no gaps. So
$$\liminf_nA_n=\bigcup_{n\ge1}\bigcap_{k\ge n}A_k=\{\omega:\ \omega\in A_n\text{ for all but finitely many }n\}.$$

People write $\{A_n\text{ i.o.}\}$ ("infinitely often") for the limsup and $\{A_n\text{ eventually}\}$ for the liminf.

*Worked example.* Three days-forever outcomes:

| Outcome | Buffer empties on days | In $\limsup_nA_n$? | In $\liminf_nA_n$? |
|---|---|---|---|
| $\omega_1$ | 1, 2, 3 only | no: finitely many | no |
| $\omega_2$ | every even day | yes: infinitely many | no: misses every odd day |
| $\omega_3$ | every day from day 5 on | yes | yes |

Facts you will use (Problem B4 proves them):

- $\liminf_nA_n\subseteq\limsup_nA_n$: "from some day on, every day" forces "infinitely many days".
- $\big(\limsup_nA_n\big)^c=\liminf_nA_n^c$: "not infinitely often" is "eventually never".
- For an increasing sequence both equal $\bigcup_nA_n$; for a decreasing sequence both equal $\bigcap_nA_n$. (For increasing $A_n$, every tail union $\bigcup_{k\ge n}A_k$ is the whole union, and $\bigcap_{k\ge n}A_k=A_n$.)

In Module 1.2 the **Borel–Cantelli lemmas** decide when $P(\limsup_nA_n)$ is $0$ or $1$. For example: if $\sum_nP(A_n)<\infty$, then with probability one only finitely many $A_n$ happen.

**Quick checks.**

1. Compute $\limsup_n[0,1/n]$ and $\liminf_n[0,1/n]$.
2. Write "blocking happens on only finitely many days" using $B_n$ = "blocking on day $n$".
3. Is $\varnothing\subseteq\{\varnothing\}$? Is $\varnothing\in\{\varnothing\}$?

*Answers.* (1) The sets decrease, so both equal $\bigcap_n[0,1/n]=\{0\}$. (2) $\big(\limsup_nB_n\big)^c=\liminf_nB_n^c$. (3) Both are true: the empty set is a subset of every set, and $\{\varnothing\}$ is the set whose one element is $\varnothing$.

## 4. Functions are random variables

### 4.1 Functions

A **function** $f:X\to Y$ is a rule that assigns to each $x\in X$ exactly one value $f(x)\in Y$. $X$ is the **domain**, $Y$ the **codomain**, and $f(X)=\{f(x):x\in X\}$ the **range**. A function does not need a formula; a table is fine.

A **random variable** is a function on the sample space. The number of taxis waiting at 6 pm is a function $X:\Omega\to\{0,1,\dots,10\}$: feed it a day, it returns that day's count.

*Running example for this section.* Split a half hour into two 15-minute slots. In each slot, either no taxi arrives (0) or one does (1). The sample space is $\Omega=\{00,01,10,11\}$, where $01$ means "no taxi in slot 1, a taxi in slot 2". Let $X$ be the number of arrivals:

| $\omega$ | 00 | 01 | 10 | 11 |
|---|---|---|---|---|
| $X(\omega)$ | 0 | 1 | 1 | 2 |

### 4.2 Image and preimage

For $A\subseteq X$ and $B\subseteq Y$:

- the **image** $f(A)=\{f(x):x\in A\}$ is where the points of $A$ go;
- the **preimage** $f^{-1}(B)=\{x\in X:f(x)\in B\}$ is everything that lands in $B$.

In the running example:

- $X^{-1}(\{1\})=\{01,10\}$: "exactly one taxi arrives";
- $X^{-1}([1,\infty))=\{01,10,11\}$: "at least one taxi arrives";
- $X^{-1}(\{5\})=\varnothing$: impossible;
- $X(\{00,01\})=\{0,1\}$.

**Notation.** Probability writes $\{X\in B\}$ for $X^{-1}(B)$, $\{X=k\}$ for $X^{-1}(\{k\})$, and $\{X\le x\}$ for $X^{-1}((-\infty,x])$. Every such expression is a preimage.

*Common mistake:* reading $f^{-1}(B)$ as "the inverse function applied to $B$". The preimage exists for **every** function, invertible or not. Here $X$ has no inverse ($01$ and $10$ both map to $1$), yet $X^{-1}(\{1\})$ is a perfectly good set.

### 4.3 Preimages respect every set operation; images do not

**Theorem.** For any function $f:X\to Y$ and any subsets $B$, $B_i$ of $Y$,
$$f^{-1}\Big(\bigcup_iB_i\Big)=\bigcup_if^{-1}(B_i),\qquad f^{-1}\Big(\bigcap_iB_i\Big)=\bigcap_if^{-1}(B_i),\qquad f^{-1}(B^c)=\big(f^{-1}(B)\big)^c .$$

*Proof of the first.* The key is that "$x\in f^{-1}(C)$" means exactly "$f(x)\in C$". So
$$x\in f^{-1}\Big(\bigcup_iB_i\Big)\iff f(x)\in\bigcup_iB_i\iff\exists i:\ f(x)\in B_i\iff\exists i:\ x\in f^{-1}(B_i)\iff x\in\bigcup_if^{-1}(B_i).$$
The other two are the same chain with "$\forall i$" or "$\notin$" (Problem B2). $\blacksquare$

**Images respect unions,** $f(\bigcup_iA_i)=\bigcup_if(A_i)$, **but not intersections or complements.** In general only $f(A\cap B)\subseteq f(A)\cap f(B)$. In the running example take $A=\{01\}$ and $B=\{10\}$. Then $A\cap B=\varnothing$, so $X(A\cap B)=\varnothing$, while $X(A)\cap X(B)=\{1\}$. The problem is that two different outcomes produce the same value. Equality holds for all $A$ and $B$ exactly when $f$ is injective (Problem B3).

**Why probability is built on preimages.** Every question about a random variable is a preimage: "at least five taxis wait at 6 pm" is $\{X\ge5\}=X^{-1}([5,\infty))$. Module 1.2 will define a random variable as a function for which every set of the form $\{X\in B\}$, for reasonable $B$, is an event. Because preimages respect complements and unions, the collection of sets $B$ that pass this test is itself closed under complements and countable unions. That is what will let you check only the half-lines, $\{X\le x\}$ for each $x$, and conclude that $\{X\in B\}$ is an event for every reasonable $B$. Images could not support this: they do not even respect intersections.

### 4.4 Injective, surjective, bijective

- $f$ is **injective** (one-to-one) if different inputs give different outputs: $f(x)=f(x')\Rightarrow x=x'$.
- $f$ is **surjective** (onto) if every element of $Y$ is hit: $f(X)=Y$.
- $f$ is **bijective** if it is both. Then each $y\in Y$ comes from exactly one $x$, and the rule $y\mapsto x$ is the **inverse function** $f^{-1}:Y\to X$, with $f^{-1}(f(x))=x$ and $f(f^{-1}(y))=y$. Conversely, a function with such a two-sided inverse is a bijection.

Examples:

- $f(x)=2x+1$ on $\mathbb R$ is bijective, with inverse $y\mapsto(y-1)/2$.
- $f(x)=x^2$ from $\mathbb R$ to $\mathbb R$ is neither: $f(-1)=f(1)$, and $-1$ is never hit. Restricted to $[0,\infty)\to[0,\infty)$ it is a bijection, with inverse $\sqrt y$. Domain and codomain are part of the function.
- $X$ in the running example is surjective onto $\{0,1,2\}$ but not injective.
- $s:\mathbb N\to\mathbb N$, $s(n)=n+1$, is injective but not surjective: $1$ is never hit. A finite set cannot map into itself injectively without being hit everywhere; only infinite sets can. Section 6 builds on this.

**Composition.** If $f:X\to Y$ and $g:Y\to Z$, then $(g\circ f)(x)=g(f(x))$, and
$$(g\circ f)^{-1}(C)=f^{-1}\big(g^{-1}(C)\big),$$
because $g(f(x))\in C\iff f(x)\in g^{-1}(C)\iff x\in f^{-1}(g^{-1}(C))$. Meaning: if $c(k)$ is the waiting cost when $k$ taxis wait, then $c(X)$ is a random cost, and its events are events about $X$: $\{c(X)\le5\}=\{X\in c^{-1}((-\infty,5])\}$. **A function of a random variable is a random variable.**

**Quick checks.**

1. For a die, $\Omega=\{1,\dots,6\}$, let $X(\omega)$ be the remainder of $\omega$ on division by $2$. Find $X^{-1}(\{0\})$.
2. Is $g:\mathbb Z\to\mathbb Z$, $g(n)=2n$, injective? Surjective?
3. In the running example, find $X^{-1}(\{0,2\})$ and its complement.

*Answers.* (1) $\{2,4,6\}$. (2) Injective, since $2n=2n'$ gives $n=n'$; not surjective, since odd numbers are never hit. (3) $\{00,11\}$ ("both slots agree"); its complement is $\{01,10\}=X^{-1}(\{1\})$, as $f^{-1}(B^c)=f^{-1}(B)^c$ predicts.

## 5. Relations and equivalence classes

A **relation** on a set $X$ is a set of pairs $R\subseteq X\times X$; write $x\sim y$ when $(x,y)\in R$. Examples: $\le$ on $\mathbb R$; "has the same remainder on division by 3" on $\mathbb Z$; "had the same queue length at 6 pm" on the set of days.

A relation is an **equivalence relation** if it behaves like equality:

- **reflexive:** $x\sim x$;
- **symmetric:** $x\sim y\Rightarrow y\sim x$;
- **transitive:** $x\sim y$ and $y\sim z$ $\Rightarrow$ $x\sim z$.

"Same remainder mod 3" and "same queue length at 6 pm" are equivalence relations. The relation $\le$ is reflexive and transitive but not symmetric, so it is not.

The **equivalence class** of $x$ is $[x]=\{y\in X:y\sim x\}$, everything that "looks the same as $x$".

**Theorem.** The equivalence classes partition $X$: every element lies in exactly one class.

*Proof.* Every $x$ lies in its own class, since $x\sim x$. It remains to show that two classes that share an element are equal. Suppose $z\in[x]\cap[y]$, so $z\sim x$ and $z\sim y$. Let $w\in[x]$, so $w\sim x$. By symmetry $x\sim z$, and then transitivity along $w\sim x$, $x\sim z$, $z\sim y$ gives $w\sim y$, so $w\in[y]$. Hence $[x]\subseteq[y]$, and by the same argument with $x$ and $y$ swapped, $[y]\subseteq[x]$. $\blacksquare$

Conversely, any partition defines an equivalence relation: "$x\sim y$ when $x$ and $y$ are in the same piece".

*Examples.* Mod 3, the classes are $\{\dots,-3,0,3,\dots\}$, $\{\dots,-2,1,4,\dots\}$ and $\{\dots,-1,2,5,\dots\}$. For "same queue length at 6 pm", the classes are the events $\{Q=q\}$, $q=0,1,2,\dots$, and they partition $\Omega$.

**Why this matters later.**

- Conditional expectation $E[X\mid Y]$ (Module 1.5) averages $X$ over each class of the partition $\{Y=y\}$: it is constant on each class.
- Lumping the states of a Markov chain into groups (Module 3.1) is choosing an equivalence relation on states.
- "$X=Y$ with probability one" is an equivalence relation on random variables, and the $L^p$ spaces of Module 0.5 are built from its classes.

## 6. Counting the infinite

### 6.1 Same size means a bijection

For finite sets, counting a set means matching its elements one-to-one with $\{1,2,\dots,n\}$. Cantor's idea was to use matching as the *definition* of size for all sets: $A$ and $B$ have the **same cardinality** if there is a bijection $A\to B$.

For infinite sets this gives surprises, sometimes told as *Hilbert's hotel*. A hotel has rooms $1,2,3,\dots$, all occupied. A new guest arrives; everyone moves from room $n$ to room $n+1$, and room $1$ is free. The map $n\mapsto n+1$ is a bijection from $\mathbb N$ onto $\{2,3,\dots\}$, so removing one element did not make the set smaller. Likewise $n\mapsto2n$ matches $\mathbb N$ with the even numbers. **An infinite set can have the same size as a part of itself**, which no finite set can.

### 6.2 Countable sets

A set is **countably infinite** if it is in bijection with $\mathbb N$, **countable** if it is finite or countably infinite, and **uncountable** otherwise. In practice, a set is countable when its elements can be listed as a sequence $a_1,a_2,a_3,\dots$ in which every element appears.

- **$\mathbb Z$ is countable:** list it as $0,1,-1,2,-2,3,-3,\dots$ (Problem A6 writes the bijection).
- **$\mathbb N\times\mathbb N$ is countable:** walk through the grid along the diagonals $m+n=2,3,4,\dots$, as in picture 3:
$$(1,1),\ (1,2),(2,1),\ (1,3),(2,2),(3,1),\ \dots$$
Every pair appears, on the diagonal $m+n$ = its sum. The formula $\pi(m,n)=2^{m-1}(2n-1)$ is another bijection (Problem B6).
- **$\mathbb Q$ is countable:** write each rational in lowest terms $p/q$ with $q\ge1$. The map $p/q\mapsto(p,q)$ is injective into $\mathbb Z\times\mathbb N$, which is countable by the same diagonal walk. A set with an injection into a countable set is countable.
- **Finite strings over a finite alphabet are countable:** there are finitely many strings of each length, so list length 1, then length 2, and so on. Every computer program is such a string, so there are only countably many programs.
- **A countable union of countable sets is countable** (Problem B6). The proof lists each set and then walks the grid of (set number, position in list). It quietly chooses one listing for each of infinitely many sets at once, which uses the *axiom of countable choice*. Without some form of choice, set theory cannot even rule out that $\mathbb R$ is a countable union of countable sets. You will use this theorem freely, but you should know what it rests on.

Two useful rules: a subset of a countable set is countable, and the image of a countable set under any function is countable.

### 6.3 Uncountable sets: the diagonal argument

**Theorem.** The set $\{0,1\}^{\mathbb N}$ of infinite $0$–$1$ sequences (coin tosses forever) is uncountable.

*Idea.* Given **any** list of sequences, build one that is missing from it.

Suppose someone claims to have listed all sequences as $s^{(1)},s^{(2)},s^{(3)},\dots$ Write them as rows of a table, and look at the diagonal:

| | toss 1 | toss 2 | toss 3 | toss 4 | toss 5 | $\cdots$ |
|---|---|---|---|---|---|---|
| $s^{(1)}$ | **0** | 1 | 1 | 0 | 1 | |
| $s^{(2)}$ | 1 | **1** | 0 | 0 | 1 | |
| $s^{(3)}$ | 0 | 0 | **0** | 1 | 1 | |
| $s^{(4)}$ | 1 | 0 | 1 | **1** | 0 | |
| $s^{(5)}$ | 0 | 1 | 0 | 1 | **0** | |

Now define $t$ by flipping each diagonal entry: $t_n=1-s^{(n)}_n$. Here $t$ begins $1,0,1,0,1,\dots$ It differs from $s^{(1)}$ in toss 1, from $s^{(2)}$ in toss 2, and in general from $s^{(n)}$ in toss $n$. So $t$ is not in the list, and the claimed list was incomplete. Since this works for **every** list, no list is complete: the set is uncountable (Problem B7 writes it out).

**$[0,1]$ is uncountable too.** Each sequence $s$ gives a number $\varphi(s)=\sum_{n\ge1}s_n2^{-n}\in[0,1]$ (its binary expansion), and every number in $[0,1]$ arises this way. A number has at most two binary expansions (for example $0.1000\ldots=0.0111\ldots$ in binary, both equal to $\tfrac12$). If $[0,1]$ were countable, $\{0,1\}^{\mathbb N}$ would be a countable union of sets with at most two elements, hence countable, which we just showed is false. So $\mathbb R$ is uncountable, and since $\mathbb Q$ is countable, so are the irrationals. Combined with the count of programs in 6.2: all but countably many real numbers cannot be computed by any program.

### 6.4 Cantor's theorem: there is always a bigger infinity

**Theorem.** For any set $X$, no function $f:X\to2^X$ is surjective.

The proof (Problem B8) uses the set $D=\{x\in X:x\notin f(x)\}$ of points that are not in the set they are sent to, and shows that $D$ cannot be $f(d)$ for any $d$, because asking whether $d\in D$ gives a contradiction either way. It is the diagonal argument in general form. Consequence: $\mathbb N$, $2^{\mathbb N}$, $2^{2^{\mathbb N}}$, … are infinite sets of ever larger sizes.

### 6.5 Comparing sizes with injections

**Schröder–Bernstein theorem** (statement only): if there is an injection $X\to Y$ and an injection $Y\to X$, then there is a bijection $X\to Y$. It saves you from building bijections by hand. *Example:* $[0,1]$ and $(0,1)$ have the same cardinality. The map $x\mapsto\tfrac14+\tfrac x2$ injects $[0,1]$ into $[\tfrac14,\tfrac34]\subseteq(0,1)$, and the inclusion injects $(0,1)$ into $[0,1]$.

### 6.6 Why this matters for probability

1. **Single outcomes can have probability zero.** For a fair coin tossed forever, a particular sequence $\omega$ occurs only if the first $n$ tosses match it, which has probability $2^{-n}$. This holds for every $n$, so $P(\{\omega\})=0$. The same is true for the exact arrival time of a taxi, or a uniform point in $[0,1]$.
2. **So probability cannot be "add up the outcomes".** If $P(E)$ were $\sum_{\omega\in E}P(\{\omega\})$, every event, including $\Omega$, would have probability $0$. Instead probability is assigned to events directly, and it is **countably additive**: for disjoint events $A_1,A_2,\dots$,
$$P\Big(\bigcup_nA_n\Big)=\sum_nP(A_n).$$
3. **Why countable is the right level.** A sum over a sequence is a series, which makes sense (Module 0.2). A sum of uncountably many *positive* numbers is always infinite. The set of positive terms is the union over $k$ of the sets of terms bigger than $1/k$; if each of those were finite, the union would be countable. So some level $1/k$ is exceeded by infinitely many terms, and the sum is infinite. There is no sensible "uncountable additivity".
4. **Discrete versus continuous.** A random variable with countably many values (such as the number of waiting taxis) has probabilities given by a list, and expectations are series. One with uncountably many values (such as a waiting time) needs integrals, and the right integral is the Lebesgue integral of Module 0.5.
5. **At the stand.** The state space of the taxi stand is countable (Problem T1), so the stand is a Markov chain on a countable state space, where sums over states make sense (Modules 3.1 and 3.3).

### I1
In plain words, what is the difference between "for every hour there is a taxi that waits more than 10 minutes" and "there is a taxi that waits more than 10 minutes in every hour"? Write both with quantifiers, and say which implies which.

#### Hint
Write both with $\forall$ and $\exists$. In which one is the taxi allowed to depend on the hour?

#### Solution
Let $W(t,h)$ mean "taxi $t$ waits more than 10 minutes in hour $h$". The first sentence is $\forall h\;\exists t\;W(t,h)$: each hour has some long-waiting taxi, possibly a different one each hour. The second is $\exists t\;\forall h\;W(t,h)$: one particular taxi waits long in every hour.

(a) "Exactly one" splits into three cases according to which event is the one that happens: only $A$, only $B$, or only $C$. "Only $A$" means $A$ happens and $B$, $C$ do not. So
$$(A\cap B^c\cap C^c)\cup(A^c\cap B\cap C^c)\cup(A^c\cap B^c\cap C).$$
The three pieces are disjoint, which matters later: their probabilities simply add.

(b) "At least two" means some pair happens together: $(A\cap B)\cup(A\cap C)\cup(B\cap C)$. These pieces overlap (an outcome in all three events is in every piece), which is fine for describing the event, but you cannot add their probabilities without correcting for the overlap.

(c) "None" means not $A$ and not $B$ and not $C$: $A^c\cap B^c\cap C^c$, which by De Morgan equals $(A\cup B\cup C)^c$, "not at least one".

(d) "$A$, but not both $B$ and $C$" is $A\cap(B\cap C)^c$, and De Morgan rewrites it as $A\cap(B^c\cup C^c)$: $A$ happens, and at least one of $B$, $C$ fails.

### A4
Show that $\mathbf 1_{A\cup B}=\mathbf 1_A+\mathbf 1_B-\mathbf 1_A\mathbf 1_B$ and $\mathbf 1_{A\triangle B}=(\mathbf 1_A-\mathbf 1_B)^2$.

#### Hint
Either check the four cases for where $\omega$ lies, or use $\mathbf 1_A^2=\mathbf 1_A$.

#### Solution
First identity: $\mathbf 1_{A\cup B}=1-\mathbf 1_{(A\cup B)^c}=1-\mathbf 1_{A^c\cap B^c}=1-(1-\mathbf 1_A)(1-\mathbf 1_B)=\mathbf 1_A+\mathbf 1_B-\mathbf 1_A\mathbf 1_B$, using De Morgan and the product rule for intersections.

Second identity: since an indicator only takes the values 0 and 1, $\mathbf 1_A^2=\mathbf 1_A$. So $(\mathbf 1_A-\mathbf 1_B)^2=\mathbf 1_A+\mathbf 1_B-2\mathbf 1_A\mathbf 1_B$. This equals 1 when exactly one of $\omega\in A$, $\omega\in B$ holds and 0 otherwise, which is $\mathbf 1_{A\triangle B}$.

### A7
Let $A_n=\big[0,\;1+(-1)^n/n\big]\subseteq\mathbb R$. Find $\limsup_n A_n$ and $\liminf_n A_n$.

#### Hint
Treat even and odd $n$ separately, and check the point $x=1$ on its own.

#### Solution
For even $n$, $A_n=[0,1+1/n]$; for odd $n$, $A_n=[0,1-1/n]$.

**Limsup.** A point $x$ lies in infinitely many $A_n$ exactly when $0\le x\le 1$: if $x\le1$ it lies in every even-indexed set; if $x>1$, then $x>1+1/n$ for all large $n$, so it lies in only finitely many sets. So $\limsup_n A_n=[0,1]$.

**Liminf.** A point $x$ lies in all but finitely many $A_n$ exactly when $0\le x<1$: if $x<1$, then $x\le1-1/n$ for all large $n$, so $x$ is in every later set, odd or even. The point $x=1$ fails, because it is outside every odd-indexed set. So $\liminf_n A_n=[0,1)$.

The difference between the two is the single point 1, which keeps switching in and out.

### B1
Prove De Morgan's law for an arbitrary indexed family: $\big(\bigcup_{i\in I}A_i\big)^c=\bigcap_{i\in I}A_i^c$.

#### Hint
Chase an element $\omega$ through a chain of "if and only if" steps.

#### Solution
For any $\omega\in\Omega$:
$$\omega\in\Big(\bigcup_iA_i\Big)^c\iff\neg\big(\exists i:\omega\in A_i\big)\iff\forall i:\ \omega\notin A_i\iff\forall i:\ \omega\in A_i^c\iff\omega\in\bigcap_iA_i^c .$$
The second step is the quantifier-negation rule from Section 1. Since the two sets have the same elements, they are equal. No assumption on the size of $I$ was used, so the law holds for uncountable families too.

### B2
Let $f:X\to Y$ and let $(B_i)_{i\in I}$ be subsets of $Y$. Prove $f^{-1}\big(\bigcup_iB_i\big)=\bigcup_if^{-1}(B_i)$, $f^{-1}\big(\bigcap_iB_i\big)=\bigcap_if^{-1}(B_i)$, and $f^{-1}(Y\setminus B)=X\setminus f^{-1}(B)$.

#### Hint
$x\in f^{-1}(C)$ means exactly $f(x)\in C$. Apply that, then the definition of union, intersection or complement.

#### Solution
Unions: $x\in f^{-1}(\bigcup_iB_i)\iff f(x)\in\bigcup_iB_i\iff\exists i:f(x)\in B_i\iff\exists i:x\in f^{-1}(B_i)\iff x\in\bigcup_if^{-1}(B_i)$.

Intersections: the same chain with "$\exists i$" replaced by "$\forall i$".

Complements: $x\in f^{-1}(Y\setminus B)\iff f(x)\notin B\iff x\notin f^{-1}(B)\iff x\in X\setminus f^{-1}(B)$.

Every step is an "if and only if", so each pair of sets is equal.

### B3
Let $f:X\to Y$. Prove that $f\big(\bigcup_iA_i\big)=\bigcup_if(A_i)$ and $f(A\cap B)\subseteq f(A)\cap f(B)$. Then prove that $f(A\cap B)=f(A)\cap f(B)$ for **all** $A,B\subseteq X$ if and only if $f$ is injective.

#### Hint
For "equality for all $A,B$ implies injective", argue by contrapositive: take two distinct points with the same image.

#### Solution
**Unions.** $y\in f(\bigcup_iA_i)\iff\exists x\in\bigcup_iA_i$ with $f(x)=y\iff\exists i\ \exists x\in A_i$ with $f(x)=y\iff y\in\bigcup_if(A_i)$.

**Inclusion.** If $y\in f(A\cap B)$, then $y=f(x)$ with $x\in A$ and $x\in B$, so $y\in f(A)$ and $y\in f(B)$.

**Injective implies equality.** Let $y\in f(A)\cap f(B)$, so $y=f(a)=f(b)$ with $a\in A$ and $b\in B$. Injectivity gives $a=b$, so $a\in A\cap B$ and $y\in f(A\cap B)$. With the inclusion above, the sets are equal.

**Equality implies injective** (contrapositive). If $f$ is not injective, pick $x_1\ne x_2$ with $f(x_1)=f(x_2)$, and set $A=\{x_1\}$, $B=\{x_2\}$. Then $f(A\cap B)=f(\varnothing)=\varnothing$, while $f(A)\cap f(B)=\{f(x_1)\}\ne\varnothing$.

### B4
Prove that $\limsup_nA_n=\{\omega:\omega\in A_n\text{ for infinitely many }n\}$ and $\liminf_nA_n=\{\omega:\omega\in A_n\text{ for all but finitely many }n\}$. Deduce that $\liminf_nA_n\subseteq\limsup_nA_n$ and that $\big(\limsup_nA_n\big)^c=\liminf_nA_n^c$.

#### Hint
Unpack $\bigcap_n\bigcup_{k\ge n}$ as "for every $n$ there is a $k\ge n$".

#### Solution
$\omega\in\bigcap_{n}\bigcup_{k\ge n}A_k\iff\forall n\ \exists k\ge n:\omega\in A_k$. If the set $\{k:\omega\in A_k\}$ were finite with largest element $K$, the choice $n=K+1$ would fail; conversely, if the set is infinite, it has elements beyond every $n$. So this is "infinitely many".

$\omega\in\bigcup_n\bigcap_{k\ge n}A_k\iff\exists n\ \forall k\ge n:\omega\in A_k$, which says the only $k$ with $\omega\notin A_k$ lie below $n$: "all but finitely many".

If $\omega$ is in $A_k$ for all $k\ge n$, it is in infinitely many $A_k$, so $\liminf\subseteq\limsup$.

Complement: apply De Morgan (B1) twice,
$$\Big(\bigcap_n\bigcup_{k\ge n}A_k\Big)^c=\bigcup_n\Big(\bigcup_{k\ge n}A_k\Big)^c=\bigcup_n\bigcap_{k\ge n}A_k^c=\liminf_nA_n^c .$$
In words: "not infinitely often" is the same as "eventually never".

### B5
Prove by induction that for finite sets $A_1,\dots,A_n$, $|A_1\cup\dots\cup A_n|\le|A_1|+\dots+|A_n|$. You may use $|A\cup B|=|A|+|B|-|A\cap B|$ for finite sets.

#### Hint
In the step, apply the two-set formula to $A_1\cup\dots\cup A_n$ and $A_{n+1}$.

#### Solution
**Base case** $n=1$: $|A_1|\le|A_1|$.

**Step.** Assume the claim for $n$ sets and let $U=A_1\cup\dots\cup A_n$. Then
$$|U\cup A_{n+1}|=|U|+|A_{n+1}|-|U\cap A_{n+1}|\le|U|+|A_{n+1}|\le|A_1|+\dots+|A_n|+|A_{n+1}|,$$
using $|U\cap A_{n+1}|\ge0$ and then the induction hypothesis. This is the counting version of the **union bound** $P(\bigcup A_i)\le\sum P(A_i)$, which you will use constantly.

### B6
(a) With $\mathbb N=\{1,2,\dots\}$, prove that $\pi(m,n)=2^{m-1}(2n-1)$ is a bijection $\mathbb N\times\mathbb N\to\mathbb N$.
(b) Prove that a countable union of countable sets is countable, and point to the exact step where infinitely many choices are made.

#### Hint
Every positive integer is a power of 2 times an odd number, in exactly one way. For (b), first show that a set $A$ is countable whenever some function from $\mathbb N$ maps **onto** it.

#### Solution
**(a)** Every $k\in\mathbb N$ can be written as $k=2^a b$ with $a\ge0$ and $b$ odd, by dividing out factors of 2 until the result is odd, and this representation is unique, by unique factorization. Set $m=a+1$ and $n=(b+1)/2$; both are positive integers and $\pi(m,n)=k$, so $\pi$ is surjective. If $\pi(m,n)=\pi(m',n')$, uniqueness gives $m-1=m'-1$ and $2n-1=2n'-1$, so $\pi$ is injective.

**(b)** *Lemma.* If $g:\mathbb N\to A$ is surjective, then $A$ is countable. For each $a\in A$ let $h(a)$ be the **smallest** $n$ with $g(n)=a$; it exists by well-ordering, so no choice is involved. $h$ is injective, since $g(h(a))=a$. So $A$ is in bijection with the subset $h(A)\subseteq\mathbb N$, and every subset of $\mathbb N$ is finite or can be listed in increasing order, hence countable.

*Theorem.* Let $A=\bigcup_{m\ge1}A_m$ with each $A_m$ countable; discard empty ones, and if all are empty then $A=\varnothing$ is countable. For each remaining $m$, **choose** a surjection $g_m:\mathbb N\to A_m$; a nonempty finite set also has one, by repeating an element. Define $G(m,n)=g_m(n)$. Then $G:\mathbb N\times\mathbb N\to A$ is surjective, so $G\circ\pi^{-1}:\mathbb N\to A$ is surjective, and the lemma finishes the proof.

The choice step is "for each $m$, choose $g_m$": infinitely many arbitrary choices made at once, which is the axiom of countable choice.

### B7
Prove that $\{0,1\}^{\mathbb N}$, the set of all infinite 0–1 sequences, is uncountable. Then explain why a fair-coin probability on this set cannot be defined by summing probabilities of individual sequences.

#### Hint
Given any list $s^{(1)},s^{(2)},\dots$ of sequences, flip the $n$-th entry of the $n$-th sequence.

#### Solution
The set is infinite: the sequences with a single 1 in position $k$ are all different. Suppose it were countable, listed as $s^{(1)},s^{(2)},\dots$. Define $t_n=1-s^{(n)}_n$. Then $t$ is a 0–1 sequence, and $t\ne s^{(n)}$ for every $n$, because they differ in position $n$. So $t$ is missing from the list, a contradiction.

For a fair coin, a fixed sequence $\omega$ can only occur if the first $n$ tosses match it, which has probability $2^{-n}$. Since this holds for every $n$, $P(\{\omega\})=0$. If $P(E)$ were $\sum_{\omega\in E}P(\{\omega\})$, every event, including the whole space, would get probability 0, not 1. (A sum of nonnegative terms over any index set is the supremum of its finite partial sums, and here every one of them is 0.) So probability must be assigned to events directly and be additive only over countable families. That is the setting of Modules 0.5 and 1.2.

### B8
Prove Cantor's theorem: for any set $X$, no function $f:X\to2^X$ is surjective.

#### Hint
Look at $D=\{x\in X:x\notin f(x)\}$.

#### Solution
Let $f:X\to2^X$ and $D=\{x\in X:x\notin f(x)\}\in2^X$. Suppose $D=f(d)$ for some $d\in X$. If $d\in D$, then by the definition of $D$, $d\notin f(d)=D$. If $d\notin D=f(d)$, then by definition $d\in D$. Both cases are contradictions, so $D$ is not in the image of $f$, and $f$ is not surjective. For finite $X$ this is just $2^{|X|}>|X|$; for infinite sets it gives an endless ladder of larger infinities.

### D1
In Python: (a) implement $\pi(m,n)=2^{m-1}(2n-1)$ and its inverse, and check by computer that every $k\le1000$ is hit exactly once. (b) Simulate 10,000 runs of 200 fair coin tosses. With $A_k$ = "heads on toss $k$", estimate the probabilities of $\bigcup_{k=150}^{200}A_k$ and $\bigcap_{k=150}^{200}A_k$, compare with the exact values, and explain what happens as the window moves off to infinity.

#### Hint
For the inverse, strip factors of 2. For (b), use NumPy's `max` and `min` along each row of a 0–1 array.

#### Solution
```python
import numpy as np

def pi(m, n):
    return 2**(m - 1) * (2*n - 1)

def pi_inv(k):
    a = 0
    while k % 2 == 0:
        k //= 2
        a += 1
    return a + 1, (k + 1) // 2

# (a) every k <= 1000 is hit exactly once (m <= 10 and n <= 500 suffice)
hits = {}
for m in range(1, 11):
    for n in range(1, 501):
        k = pi(m, n)
        if k <= 1000:
            hits[k] = hits.get(k, 0) + 1
assert sorted(hits) == list(range(1, 1001)) and set(hits.values()) == {1}
assert all(pi(*pi_inv(k)) == k for k in range(1, 1001))

# (b) union and intersection over tosses 150..200 (51 tosses)
rng = np.random.default_rng(0)
X = rng.integers(0, 2, size=(10_000, 200))   # column k-1 is toss k, 1 = heads
win = X[:, 149:200]
print("union        ~", (win.max(axis=1) == 1).mean(), " exact", 1 - 2.0**-51)
print("intersection ~", (win.min(axis=1) == 1).mean(), " exact", 2.0**-51)
```
The union comes out as 1.0 and the intersection as 0.0, matching $1-2^{-51}$ and $2^{-51}$ to the precision 10,000 runs can show.

As the window $[n,\infty)$ moves out, $P\big(\bigcup_{k\ge n}A_k\big)=1$ for every $n$, so $P(\limsup_nA_n)=1$: heads occurs infinitely often. And $P\big(\bigcap_{k\ge n}A_k\big)=0$ for every $n$, so $P(\liminf_nA_n)=0$. Passing to the limit uses continuity of probability, which Module 1.2 proves; the second Borel–Cantelli lemma gives the first fact directly.

### T1
At the stand, taxis and passengers are matched instantly, so taxis and passengers never wait at the same time. #### Solution
**Well defined.** $q-k\ge-k\ge-K$, so $\varphi$ lands in the target set.

**Injective.** Let $z=\varphi(k,q)$ for some $(k,q)\in S$. If $z>0$, then $q>k\ge0$, so $q>0$, hence $k=0$ (because $kq=0$) and $q=z$. If $z<0$, then $k>q\ge0$, so $k>0$, hence $q=0$ and $k=-z$. **Surjective.** For $z\ge0$ take $(0,z)\in S$. For $-K\le z<0$ take $(-z,0)\in S$.
