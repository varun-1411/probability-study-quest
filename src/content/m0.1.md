## The story

At the taxi stand, an *event* is a statement about what happened: "at least five taxis were waiting at 6 pm", "the passenger queue emptied before 7 pm", "a taxi was turned away because the buffer was full". Probability will attach a number to each event. Before it can, you need three things:

- a precise way to **combine** events: and, or, not, and "infinitely often";
- a precise way to describe **random quantities**, such as the number of waiting taxis, as functions of the outcome;
- a way to **count** how many outcomes there can be, because probability adds over countable lists and breaks down beyond them.

So in this module: *sets are events, functions are random variables, and countability explains why probability is only countably additive.*

## The picture

2. Two blobs $X$ and $Y$ with arrows from points of $X$ to points of $Y$ (a function). Circle a set $B\subseteq Y$, then circle everything in $X$ whose arrow lands in $B$. That circled set is the **preimage** $f^{-1}(B)$, and it is the most important object in this module.
3. A grid of dots $(m,n)$ with a zig-zag path through them: the proof that $\mathbb{N}\times\mathbb{N}$ is countable.

## 1. Logic you will use every day

A statement is either true or false. Build bigger ones with $\wedge$ (and), $\vee$ (or), $\neg$ (not), $\Rightarrow$ (implies) and $\Leftrightarrow$ (if and only if).

- $P\Rightarrow Q$ is false only when $P$ is true and $Q$ is false.
- The **contrapositive** $\neg Q\Rightarrow\neg P$ says exactly the same thing as $P\Rightarrow Q$. The **converse** $Q\Rightarrow P$ does not.

**Quantifiers.** $\forall x$ ("for every $x$") and $\exists x$ ("there is an $x$"). Negation swaps them:
$$\neg\big(\forall x\; P(x)\big)\iff \exists x\;\neg P(x),\qquad \neg\big(\exists x\; P(x)\big)\iff \forall x\;\neg P(x).$$

**Order matters.** "For every hour $h$ there is a taxi $t$ that waits" ($\forall h\,\exists t$) lets the taxi change with the hour. "There is a taxi $t$ that waits in every hour" ($\exists t\,\forall h$) asks for one taxi that works all day. The second implies the first, not the other way round. The definition of a limit, $\forall\varepsilon>0\;\exists N\;\forall n\ge N\;|x_n-x|<\varepsilon$, depends entirely on this order: $N$ may depend on $\varepsilon$.

## 2. Proof techniques

**Direct proof.** Assume the hypothesis, reach the conclusion. *If $n$ is odd, $n^2$ is odd:* write $n=2k+1$, so $n^2=2(2k^2+2k)+1$.

**Contrapositive.** *If $n^2$ is even, $n$ is even.* Prove instead: if $n$ is odd, $n^2$ is odd, which we just did.

**Contradiction.** *$\sqrt2$ is irrational.* Suppose $\sqrt2=p/q$ in lowest terms. Then $p^2=2q^2$, so $p^2$ is even, so $p$ is even, say $p=2r$. Then $q^2=2r^2$, so $q$ is even too, contradicting lowest terms.

**Induction.** To prove $P(n)$ for all $n\ge1$: prove $P(1)$, then prove $P(n)\Rightarrow P(n+1)$. Strong induction assumes $P(1),\dots,P(n)$ in the step. You will use induction to go from two events to $n$ events, for example from $|A\cup B|\le|A|+|B|$ to the union bound for $n$ sets (Problem B5).

**Counterexample.** One example kills a "for all" claim. "Every function satisfies $f(A\cap B)=f(A)\cap f(B)$" dies with $f(x)=x^2$, $A=[-1,0]$, $B=[0,1]$ (Problem A5).

## 3. Sets are events

Fix a set $\Omega$, the **sample space**: every possible outcome, for example every possible day at the stand. Subsets of $\Omega$ are events.

| Set language | Event language |
|---|---|
| $\omega\in A$ | $A$ happened on outcome $\omega$ |
| $A\cup B$ | $A$ or $B$ (or both) |
| $A\cap B$ | $A$ and $B$ |
| $A^c=\Omega\setminus A$ | $A$ did not happen |
| $A\setminus B=A\cap B^c$ | $A$ but not $B$ |
| $A\triangle B=(A\setminus B)\cup(B\setminus A)$ | exactly one of $A$, $B$ |
| $A\subseteq B$ | $A$ forces $B$ |
| $A\cap B=\varnothing$ | $A$ and $B$ cannot both happen |

**De Morgan's laws.** $(A\cup B)^c=A^c\cap B^c$ and $(A\cap B)^c=A^c\cup B^c$. Proof by element chasing: $\omega\in(A\cup B)^c\iff\omega\notin A\cup B\iff(\omega\notin A\text{ and }\omega\notin B)\iff\omega\in A^c\cap B^c$. The same argument works for any family $(A_i)_{i\in I}$, finite or not (Problem B1):
$$\Big(\bigcup_{i\in I}A_i\Big)^c=\bigcap_{i\in I}A_i^c,\qquad \Big(\bigcap_{i\in I}A_i\Big)^c=\bigcup_{i\in I}A_i^c.$$

**Indicator functions** turn set algebra into ordinary algebra. Define $\mathbf 1_A(\omega)=1$ if $\omega\in A$ and $0$ otherwise. Then
$$\mathbf 1_{A\cap B}=\mathbf 1_A\mathbf 1_B,\qquad \mathbf 1_{A^c}=1-\mathbf 1_A,\qquad \mathbf 1_{A\cup B}=\mathbf 1_A+\mathbf 1_B-\mathbf 1_A\mathbf 1_B .$$
Later, the expected value of $\mathbf 1_A$ will be exactly $P(A)$, so these identities become probability rules for free.

**Limsup and liminf of sets.** For a sequence of events $A_1,A_2,\dots$ define
$$\limsup_{n}A_n=\bigcap_{n\ge1}\bigcup_{k\ge n}A_k,\qquad \liminf_{n}A_n=\bigcup_{n\ge1}\bigcap_{k\ge n}A_k .$$
In plain words: $\omega\in\limsup A_n$ means $A_n$ happens **infinitely often**, and $\omega\in\liminf A_n$ means $A_n$ happens **eventually always** (for all but finitely many $n$). If $A_n$ is "the buffer empties on day $n$", then $\limsup A_n$ is "the buffer empties on infinitely many days". Module 1.2's Borel–Cantelli lemmas tell you when this event has probability 0 or 1.

## 4. Functions are random variables

A function $f:X\to Y$ assigns one $f(x)\in Y$ to each $x\in X$. For $A\subseteq X$ and $B\subseteq Y$:

- the **image** is $f(A)=\{f(x):x\in A\}$;
- the **preimage** is $f^{-1}(B)=\{x\in X: f(x)\in B\}$.

The preimage exists for every function, invertible or not. $f^{-1}(B)$ is a set, not the value of an inverse function.

**The key fact.** Preimages respect every set operation:
$$f^{-1}\Big(\bigcup_i B_i\Big)=\bigcup_i f^{-1}(B_i),\qquad f^{-1}\Big(\bigcap_i B_i\Big)=\bigcap_i f^{-1}(B_i),\qquad f^{-1}(B^c)=\big(f^{-1}(B)\big)^c .$$
Images respect unions, $f(\bigcup_i A_i)=\bigcup_i f(A_i)$, but **not** intersections or complements: in general only $f(A\cap B)\subseteq f(A)\cap f(B)$, with equality for all $A,B$ exactly when $f$ is injective (Problem B3).

This is why probability theory is built on preimages. Let $X(\omega)$ be the number of taxis waiting at 6 pm on day $\omega$. Then "at least five taxis wait" is the event
$$\{X\ge5\}=\{\omega:X(\omega)\ge5\}=X^{-1}\big([5,\infty)\big).$$
A random variable will be a function whose preimages of reasonable sets are always events, and because preimages respect unions, intersections and complements, that requirement behaves well.

**Vocabulary.** $f$ is **injective** if $f(x)=f(x')\Rightarrow x=x'$, **surjective** if $f(X)=Y$, and **bijective** if both; a bijection has an inverse $f^{-1}:Y\to X$. For a composition, $(g\circ f)^{-1}(C)=f^{-1}\big(g^{-1}(C)\big)$, which later shows that a function of a random variable is a random variable.

## 5. Relations and equivalence classes

A **relation** on $X$ is a set of pairs $R\subseteq X\times X$; write $x\sim y$ for $(x,y)\in R$. It is an **equivalence relation** if it is reflexive ($x\sim x$), symmetric ($x\sim y\Rightarrow y\sim x$) and transitive ($x\sim y,\ y\sim z\Rightarrow x\sim z$). The **equivalence class** of $x$ is $[x]=\{y:y\sim x\}$, and the classes **partition** $X$: every element lies in exactly one class.

Example: call two days equivalent if they had the same queue length at 6 pm. Each class is a set $\{Q=q\}$, and the classes partition $\Omega$. Later, "equal almost surely" is an equivalence relation on random variables, and the $L^p$ spaces of Module 0.5 are built from its classes.

## 6. Counting the infinite

Two sets have the **same cardinality** if a bijection exists between them. A set is **countably infinite** if it is in bijection with $\mathbb N=\{1,2,3,\dots\}$, **countable** if it is finite or countably infinite, and **uncountable** otherwise.

- $\mathbb Z$ is countable: list $0,1,-1,2,-2,\dots$ (Problem A6).
- $\mathbb N\times\mathbb N$ is countable: $\pi(m,n)=2^{m-1}(2n-1)$ is a bijection onto $\mathbb N$ (Problem B6). So $\mathbb Q$ is countable too.
- **A countable union of countable sets is countable** (Problem B6). The proof picks an enumeration of each set, infinitely many choices at once, which uses the axiom of countable choice. Without some choice, it is consistent with set theory that $\mathbb R$ is a countable union of countable sets. You will use this theorem without worry, but you should know where it rests.
- **$\{0,1\}^{\mathbb N}$, the set of infinite coin-toss sequences, is uncountable** (Cantor's diagonal argument, Problem B7). So is $[0,1]$.
- **Cantor's theorem**: no set $X$ maps onto its power set $2^X$ (Problem B8).
- **Schröder–Bernstein** (statement only): if there are injections $X\to Y$ and $Y\to X$, there is a bijection $X\to Y$.

**Why this matters for probability.** For a fair coin tossed forever, any single sequence $\omega$ has probability 0: it must match the first $n$ tosses, which has probability $2^{-n}$, for every $n$. If probabilities of events were sums over their outcomes, the whole space would have probability 0, not 1. So probability is defined on events directly, and it is **countably** additive, never uncountably additive. Making that consistent is the job of measure theory (Modules 0.5 and 1.2).

### I1
In plain words, what is the difference between "for every hour there is a taxi that waits more than 10 minutes" and "there is a taxi that waits more than 10 minutes in every hour"? Write both with quantifiers, and say which implies which.

#### Hint
Write both with $\forall$ and $\exists$. In which one is the taxi allowed to depend on the hour?

#### Solution
Let $W(t,h)$ mean "taxi $t$ waits more than 10 minutes in hour $h$". The first sentence is $\forall h\;\exists t\;W(t,h)$: each hour has some long-waiting taxi, possibly a different one each hour. The second is $\exists t\;\forall h\;W(t,h)$: one particular taxi waits long in every hour.

The second implies the first: take the same $t$ for every $h$. The first does not imply the second: taxi 1 might wait long only from 6 to 7 pm and taxi 2 only from 7 to 8 pm. Then every hour has a long-waiting taxi, but no single taxi does it every hour.

### I2
Let $A_n$ be the event "the buffer empties on day $n$". Explain in words why $\limsup_n A_n$ means "$A_n$ happens infinitely often". Then take an outcome $\omega$ in which the buffer empties on exactly the even days. Is $\omega$ in $\limsup_n A_n$? In $\liminf_n A_n$?

#### Hint
For this $\omega$, ask two questions: is $\omega\in A_n$ for infinitely many $n$? Is $\omega\in A_n$ for all large $n$?

#### Solution
$\omega\in\bigcap_{n}\bigcup_{k\ge n}A_k$ says: for every starting day $n$, some later day $k\ge n$ has $\omega\in A_k$. "There is always another one later" is exactly "infinitely many".

For the even-days outcome: after any day $n$ there is a later even day, so $\omega\in\limsup_n A_n$. But $\omega\notin\liminf_n A_n$, because that needs $\omega\in A_k$ for **all** $k$ beyond some $N$, and every odd day fails. This is the typical picture: $\liminf\subseteq\limsup$, and the gap holds the outcomes that keep switching in and out.

### I3
Why are "measurable" sets and random variables defined using preimages $f^{-1}(B)$ rather than images $f(A)$? Answer in two or three sentences.

#### Hint
Which of $f$ and $f^{-1}$ commutes with complements and intersections?

#### Solution
Preimages respect unions, intersections and complements, so the collection of sets $B$ whose preimage is an event is closed under the same operations as the events themselves. That is what lets one check, say, $\{X\le x\}$ for each $x$ and conclude that $\{X\in B\}$ is an event for every reasonable $B$. Images fail this: $f(A\cap B)$ can be strictly smaller than $f(A)\cap f(B)$, and $f(A^c)$ need not be $f(A)^c$, so a definition built on images would not survive the operations probability needs.

### A1
Write the negation of "for every $\varepsilon>0$ there exists $N$ such that for all $n\ge N$, $|x_n-x|<\varepsilon$", with no $\neg$ left in front of a quantifier. What does it say in words?

#### Hint
Flip every quantifier and negate the inequality at the end.

#### Solution
$$\exists\,\varepsilon>0\;\;\forall N\;\;\exists\,n\ge N:\;|x_n-x|\ge\varepsilon .$$
In words: there is a fixed tolerance $\varepsilon$ that the sequence breaks again and again, however far out you go. That is precisely "$x_n$ does not converge to $x$".

### A2
Let $\Omega=\{1,\dots,6\}$, $A=\{1,2,3\}$, $B=\{2,4,6\}$, $C=\{3,4,5\}$. Compute $A\cup B$, $A\cap C$, $B^c$, $A\setminus B$, $A\triangle C$ and $(A\cup B)^c\cap C$. Check De Morgan's law $(A\cup B)^c=A^c\cap B^c$ by listing elements.

#### Hint
$A\triangle C=(A\setminus C)\cup(C\setminus A)$.

#### Solution
$A\cup B=\{1,2,3,4,6\}$, $A\cap C=\{3\}$, $B^c=\{1,3,5\}$, $A\setminus B=\{1,3\}$, $A\triangle C=\{1,2\}\cup\{4,5\}=\{1,2,4,5\}$, and $(A\cup B)^c\cap C=\{5\}\cap\{3,4,5\}=\{5\}$.

De Morgan: $(A\cup B)^c=\{5\}$ and $A^c\cap B^c=\{4,5,6\}\cap\{1,3,5\}=\{5\}$. They agree.

### A3
For events $A$, $B$, $C$, write each of the following with $\cup$, $\cap$ and complements: (a) exactly one of them happens; (b) at least two happen; (c) none happens; (d) $A$ happens but not both $B$ and $C$.

#### Hint
"Exactly one" is a union of three pieces that cannot overlap.

#### Solution
(a) $(A\cap B^c\cap C^c)\cup(A^c\cap B\cap C^c)\cup(A^c\cap B^c\cap C)$.

(b) $(A\cap B)\cup(A\cap C)\cup(B\cap C)$.

(c) $A^c\cap B^c\cap C^c$, which by De Morgan equals $(A\cup B\cup C)^c$.

(d) $A\cap(B\cap C)^c=A\cap(B^c\cup C^c)$.

### A4
Show that $\mathbf 1_{A\cup B}=\mathbf 1_A+\mathbf 1_B-\mathbf 1_A\mathbf 1_B$ and $\mathbf 1_{A\triangle B}=(\mathbf 1_A-\mathbf 1_B)^2$.

#### Hint
Either check the four cases for where $\omega$ lies, or use $\mathbf 1_A^2=\mathbf 1_A$.

#### Solution
First identity: $\mathbf 1_{A\cup B}=1-\mathbf 1_{(A\cup B)^c}=1-\mathbf 1_{A^c\cap B^c}=1-(1-\mathbf 1_A)(1-\mathbf 1_B)=\mathbf 1_A+\mathbf 1_B-\mathbf 1_A\mathbf 1_B$, using De Morgan and the product rule for intersections.

Second identity: since an indicator only takes the values 0 and 1, $\mathbf 1_A^2=\mathbf 1_A$. So $(\mathbf 1_A-\mathbf 1_B)^2=\mathbf 1_A+\mathbf 1_B-2\mathbf 1_A\mathbf 1_B$. This equals 1 when exactly one of $\omega\in A$, $\omega\in B$ holds and 0 otherwise, which is $\mathbf 1_{A\triangle B}$.

### A5
Let $f:\mathbb R\to\mathbb R$, $f(x)=x^2$. Compute $f([-1,2])$, $f^{-1}([1,4])$, $f^{-1}((-\infty,0))$ and $f^{-1}([0,1])$. Then compute $f([-1,0]\cap[0,1])$ and $f([-1,0])\cap f([0,1])$, and compare.

#### Hint
Solve $x^2\in[1,4]$ for $x$. For images of intervals, find the smallest and largest values of $x^2$ on the interval.

#### Solution
$f([-1,2])=[0,4]$ (the minimum 0 is at $x=0$, the maximum 4 at $x=2$). $f^{-1}([1,4])=\{x:1\le x^2\le4\}=[-2,-1]\cup[1,2]$. $f^{-1}((-\infty,0))=\varnothing$, since no square is negative. $f^{-1}([0,1])=[-1,1]$.

$[-1,0]\cap[0,1]=\{0\}$, so $f([-1,0]\cap[0,1])=\{0\}$. But $f([-1,0])=[0,1]$ and $f([0,1])=[0,1]$, so their intersection is $[0,1]$. The inclusion $f(A\cap B)\subseteq f(A)\cap f(B)$ is strict here because $f$ is not injective: $f(-x)=f(x)$.

### A6
Give an explicit bijection $g:\mathbb N\to\mathbb Z$ (with $\mathbb N=\{1,2,3,\dots\}$) and its inverse.

#### Hint
Send even numbers to the positive integers and odd numbers to $0,-1,-2,\dots$

#### Solution
$g(n)=n/2$ if $n$ is even and $g(n)=-(n-1)/2$ if $n$ is odd. So $g(1)=0$, $g(2)=1$, $g(3)=-1$, $g(4)=2$, $g(5)=-2,\dots$

The inverse is $h(z)=2z$ for $z>0$ and $h(z)=1-2z$ for $z\le0$. Check: $h(g(n))=n$ in both cases (for even $n$, $h(n/2)=n$; for odd $n$, $h(-(n-1)/2)=1+(n-1)=n$), and $g(h(z))=z$ likewise. A function with a two-sided inverse is a bijection.

### A7
Let $A_n=\big[0,\;1+(-1)^n/n\big]\subseteq\mathbb R$. Find $\limsup_n A_n$ and $\liminf_n A_n$.

#### Hint
Treat even and odd $n$ separately, and check the point $x=1$ on its own.

#### Solution
For even $n$, $A_n=[0,1+1/n]$; for odd $n$, $A_n=[0,1-1/n]$.

**Limsup.** A point $x$ lies in infinitely many $A_n$ exactly when $0\le x\le 1$: if $x\le1$ it lies in every even-indexed set; if $x>1$, then $x>1+1/n$ for all large $n$, so it lies in only finitely many sets. So $\limsup_n A_n=[0,1]$.

**Liminf.** A point $x$ lies in all but finitely many $A_n$ exactly when $0\le x<1$: if $x<1$, then $x\le1-1/n$ for all large $n$, so $x$ is in every later set, odd or even. The point $x=1$ fails, because it is outside every odd-indexed set. So $\liminf_n A_n=[0,1)$.

The difference between the two is the single point 1, which keeps switching in and out.

### B1
Prove De Morgan's law for an arbitrary indexed family: $\big(\bigcup_{i\in I}A_i\big)^c=\bigcap_{i\in I}A_i^c$.

#### Hint
Chase an element $\omega$ through a chain of "if and only if" steps.

#### Solution
For any $\omega\in\Omega$:
$$\omega\in\Big(\bigcup_iA_i\Big)^c\iff\neg\big(\exists i:\omega\in A_i\big)\iff\forall i:\ \omega\notin A_i\iff\forall i:\ \omega\in A_i^c\iff\omega\in\bigcap_iA_i^c .$$
The second step is the quantifier-negation rule from Section 1. Since the two sets have the same elements, they are equal. No assumption on the size of $I$ was used, so the law holds for uncountable families too.

### B2
Let $f:X\to Y$ and let $(B_i)_{i\in I}$ be subsets of $Y$. Prove $f^{-1}\big(\bigcup_iB_i\big)=\bigcup_if^{-1}(B_i)$, $f^{-1}\big(\bigcap_iB_i\big)=\bigcap_if^{-1}(B_i)$, and $f^{-1}(Y\setminus B)=X\setminus f^{-1}(B)$.

#### Hint
$x\in f^{-1}(C)$ means exactly $f(x)\in C$. Apply that, then the definition of union, intersection or complement.

#### Solution
Unions: $x\in f^{-1}(\bigcup_iB_i)\iff f(x)\in\bigcup_iB_i\iff\exists i:f(x)\in B_i\iff\exists i:x\in f^{-1}(B_i)\iff x\in\bigcup_if^{-1}(B_i)$.

Intersections: the same chain with "$\exists i$" replaced by "$\forall i$".

Complements: $x\in f^{-1}(Y\setminus B)\iff f(x)\notin B\iff x\notin f^{-1}(B)\iff x\in X\setminus f^{-1}(B)$.

Every step is an "if and only if", so each pair of sets is equal.

### B3
Let $f:X\to Y$. Prove that $f\big(\bigcup_iA_i\big)=\bigcup_if(A_i)$ and $f(A\cap B)\subseteq f(A)\cap f(B)$. Then prove that $f(A\cap B)=f(A)\cap f(B)$ for **all** $A,B\subseteq X$ if and only if $f$ is injective.

#### Hint
For "equality for all $A,B$ implies injective", argue by contrapositive: take two distinct points with the same image.

#### Solution
**Unions.** $y\in f(\bigcup_iA_i)\iff\exists x\in\bigcup_iA_i$ with $f(x)=y\iff\exists i\ \exists x\in A_i$ with $f(x)=y\iff y\in\bigcup_if(A_i)$.

**Inclusion.** If $y\in f(A\cap B)$, then $y=f(x)$ with $x\in A$ and $x\in B$, so $y\in f(A)$ and $y\in f(B)$.

**Injective implies equality.** Let $y\in f(A)\cap f(B)$, so $y=f(a)=f(b)$ with $a\in A$ and $b\in B$. Injectivity gives $a=b$, so $a\in A\cap B$ and $y\in f(A\cap B)$. With the inclusion above, the sets are equal.

**Equality implies injective** (contrapositive). If $f$ is not injective, pick $x_1\ne x_2$ with $f(x_1)=f(x_2)$, and set $A=\{x_1\}$, $B=\{x_2\}$. Then $f(A\cap B)=f(\varnothing)=\varnothing$, while $f(A)\cap f(B)=\{f(x_1)\}\ne\varnothing$.

### B4
Prove that $\limsup_nA_n=\{\omega:\omega\in A_n\text{ for infinitely many }n\}$ and $\liminf_nA_n=\{\omega:\omega\in A_n\text{ for all but finitely many }n\}$. Deduce that $\liminf_nA_n\subseteq\limsup_nA_n$ and that $\big(\limsup_nA_n\big)^c=\liminf_nA_n^c$.

#### Hint
Unpack $\bigcap_n\bigcup_{k\ge n}$ as "for every $n$ there is a $k\ge n$".

#### Solution
$\omega\in\bigcap_{n}\bigcup_{k\ge n}A_k\iff\forall n\ \exists k\ge n:\omega\in A_k$. If the set $\{k:\omega\in A_k\}$ were finite with largest element $K$, the choice $n=K+1$ would fail; conversely, if the set is infinite, it has elements beyond every $n$. So this is "infinitely many".

$\omega\in\bigcup_n\bigcap_{k\ge n}A_k\iff\exists n\ \forall k\ge n:\omega\in A_k$, which says the only $k$ with $\omega\notin A_k$ lie below $n$: "all but finitely many".

If $\omega$ is in $A_k$ for all $k\ge n$, it is in infinitely many $A_k$, so $\liminf\subseteq\limsup$.

Complement: apply De Morgan (B1) twice,
$$\Big(\bigcap_n\bigcup_{k\ge n}A_k\Big)^c=\bigcup_n\Big(\bigcup_{k\ge n}A_k\Big)^c=\bigcup_n\bigcap_{k\ge n}A_k^c=\liminf_nA_n^c .$$
In words: "not infinitely often" is the same as "eventually never".

### B5
Prove by induction that for finite sets $A_1,\dots,A_n$, $|A_1\cup\dots\cup A_n|\le|A_1|+\dots+|A_n|$. You may use $|A\cup B|=|A|+|B|-|A\cap B|$ for finite sets.

#### Hint
In the step, apply the two-set formula to $A_1\cup\dots\cup A_n$ and $A_{n+1}$.

#### Solution
**Base case** $n=1$: $|A_1|\le|A_1|$.

**Step.** Assume the claim for $n$ sets and let $U=A_1\cup\dots\cup A_n$. Then
$$|U\cup A_{n+1}|=|U|+|A_{n+1}|-|U\cap A_{n+1}|\le|U|+|A_{n+1}|\le|A_1|+\dots+|A_n|+|A_{n+1}|,$$
using $|U\cap A_{n+1}|\ge0$ and then the induction hypothesis. This is the counting version of the **union bound** $P(\bigcup A_i)\le\sum P(A_i)$, which you will use constantly.

### B6
(a) With $\mathbb N=\{1,2,\dots\}$, prove that $\pi(m,n)=2^{m-1}(2n-1)$ is a bijection $\mathbb N\times\mathbb N\to\mathbb N$.
(b) Prove that a countable union of countable sets is countable, and point to the exact step where infinitely many choices are made.

#### Hint
Every positive integer is a power of 2 times an odd number, in exactly one way. For (b), first show that a set $A$ is countable whenever some function from $\mathbb N$ maps **onto** it.

#### Solution
**(a)** Every $k\in\mathbb N$ can be written as $k=2^a b$ with $a\ge0$ and $b$ odd, by dividing out factors of 2 until the result is odd, and this representation is unique, by unique factorization. Set $m=a+1$ and $n=(b+1)/2$; both are positive integers and $\pi(m,n)=k$, so $\pi$ is surjective. If $\pi(m,n)=\pi(m',n')$, uniqueness gives $m-1=m'-1$ and $2n-1=2n'-1$, so $\pi$ is injective.

**(b)** *Lemma.* If $g:\mathbb N\to A$ is surjective, then $A$ is countable. For each $a\in A$ let $h(a)$ be the **smallest** $n$ with $g(n)=a$; it exists by well-ordering, so no choice is involved. $h$ is injective, since $g(h(a))=a$. So $A$ is in bijection with the subset $h(A)\subseteq\mathbb N$, and every subset of $\mathbb N$ is finite or can be listed in increasing order, hence countable.

*Theorem.* Let $A=\bigcup_{m\ge1}A_m$ with each $A_m$ countable; discard empty ones, and if all are empty then $A=\varnothing$ is countable. For each remaining $m$, **choose** a surjection $g_m:\mathbb N\to A_m$; a nonempty finite set also has one, by repeating an element. Define $G(m,n)=g_m(n)$. Then $G:\mathbb N\times\mathbb N\to A$ is surjective, so $G\circ\pi^{-1}:\mathbb N\to A$ is surjective, and the lemma finishes the proof.

The choice step is "for each $m$, choose $g_m$": infinitely many arbitrary choices made at once, which is the axiom of countable choice.

### B7
Prove that $\{0,1\}^{\mathbb N}$, the set of all infinite 0–1 sequences, is uncountable. Then explain why a fair-coin probability on this set cannot be defined by summing probabilities of individual sequences.

#### Hint
Given any list $s^{(1)},s^{(2)},\dots$ of sequences, flip the $n$-th entry of the $n$-th sequence.

#### Solution
The set is infinite: the sequences with a single 1 in position $k$ are all different. Suppose it were countable, listed as $s^{(1)},s^{(2)},\dots$. Define $t_n=1-s^{(n)}_n$. Then $t$ is a 0–1 sequence, and $t\ne s^{(n)}$ for every $n$, because they differ in position $n$. So $t$ is missing from the list, a contradiction.

For a fair coin, a fixed sequence $\omega$ can only occur if the first $n$ tosses match it, which has probability $2^{-n}$. Since this holds for every $n$, $P(\{\omega\})=0$. If $P(E)$ were $\sum_{\omega\in E}P(\{\omega\})$, every event, including the whole space, would get probability 0, not 1. (A sum of nonnegative terms over any index set is the supremum of its finite partial sums, and here every one of them is 0.) So probability must be assigned to events directly and be additive only over countable families. That is the setting of Modules 0.5 and 1.2.

### B8
Prove Cantor's theorem: for any set $X$, no function $f:X\to2^X$ is surjective.

#### Hint
Look at $D=\{x\in X:x\notin f(x)\}$.

#### Solution
Let $f:X\to2^X$ and $D=\{x\in X:x\notin f(x)\}\in2^X$. Suppose $D=f(d)$ for some $d\in X$. If $d\in D$, then by the definition of $D$, $d\notin f(d)=D$. If $d\notin D=f(d)$, then by definition $d\in D$. Both cases are contradictions, so $D$ is not in the image of $f$, and $f$ is not surjective. For finite $X$ this is just $2^{|X|}>|X|$; for infinite sets it gives an endless ladder of larger infinities.

### C1
An airport has three terminals. Let $T_i$ be the event "a taxi is waiting at terminal $i$ at 18:00", and write $t_i=\mathbf 1_{T_i}$. (a) Write "at least one terminal has a waiting taxi" as a set and as an indicator expression. (b) Do the same for "exactly one terminal has none". (c) The dispatcher's alarm fires when fewer than two terminals have a taxi. Write the alarm event, and express its indicator as a polynomial in $t_1,t_2,t_3$.

"At least one" is the complement of "none". For (c), compute the indicator of "at least two" first.

#### Solution
(a) $T_1\cup T_2\cup T_3$, with indicator $1-(1-t_1)(1-t_2)(1-t_3)$.

(b) Exactly one terminal has none means exactly two have a taxi: $(T_1\cap T_2\cap T_3^c)\cup(T_1\cap T_2^c\cap T_3)\cup(T_1^c\cap T_2\cap T_3)$, with indicator $t_1t_2(1-t_3)+t_1(1-t_2)t_3+(1-t_1)t_2t_3$.

(c) The alarm event is the complement of "at least two have a taxi": $\big[(T_1\cap T_2)\cup(T_1\cap T_3)\cup(T_2\cap T_3)\big]^c$. "At least two" = "exactly two" plus "all three", with indicator
$$t_1t_2+t_1t_3+t_2t_3-3t_1t_2t_3+t_1t_2t_3=t_1t_2+t_1t_3+t_2t_3-2t_1t_2t_3 .$$

### C2
Let $\Omega$ be the set of possible days. Let $Q(\omega)\in\{0,1,2,\dots\}$ be the number of passengers queuing and $K(\omega)\in\{0,\dots,K_{\max}\}$ the number of taxis waiting at 18:00. Prove that
$$\{Q>K\}=\bigcup_{k=0}^{K_{\max}}\big(\{K=k\}\cap\{Q\ge k+1\}\big),$$
and explain why this is good news: if every set $\{K=k\}$ and $\{Q\ge j\}$ is an event, so is $\{Q>K\}$.

#### Hint
Split according to the value that $K$ takes on the given day.

#### Solution
($\subseteq$) Let $\omega$ satisfy $Q(\omega)>K(\omega)$ and put $k=K(\omega)$. Then $0\le k\le K_{\max}$, and since $Q(\omega)$ is an integer bigger than $k$, $Q(\omega)\ge k+1$. So $\omega$ lies in the $k$-th set of the union.

($\supseteq$) If $\omega\in\{K=k\}\cap\{Q\ge k+1\}$, then $Q(\omega)\ge k+1>k=K(\omega)$.

Each piece is a preimage: $\{K=k\}=K^{-1}(\{k\})$ and $\{Q\ge k+1\}=Q^{-1}([k+1,\infty))$. Events will be closed under countable unions and intersections, so a comparison of two random variables, which is not a preimage under either one alone, is still an event. Here the union is even finite, because the buffer is finite.

### C3
Let $B_n$ be the event "a taxi is blocked (turned away by a full buffer) on day $n$". Management claims a new policy makes blocking **eventually stop**. Write the claim as an event using $\liminf$ or $\limsup$. Then write its negation and say what it means.

#### Hint
"Eventually stops" means: from some day on, never again.

#### Solution
"From some day $N$ on, no blocking" is $\bigcup_N\bigcap_{n\ge N}B_n^c=\liminf_nB_n^c$. By B4 this equals $\big(\limsup_nB_n\big)^c$.

The negation is $\limsup_nB_n$: blocking happens on infinitely many days. The claim, made precise, is $P(\limsup_n B_n)=0$, and the first Borel–Cantelli lemma (Module 1.2) proves it whenever $\sum_nP(B_n)<\infty$.

### D1
In Python: (a) implement $\pi(m,n)=2^{m-1}(2n-1)$ and its inverse, and check by computer that every $k\le1000$ is hit exactly once. (b) Simulate 10,000 runs of 200 fair coin tosses. With $A_k$ = "heads on toss $k$", estimate the probabilities of $\bigcup_{k=150}^{200}A_k$ and $\bigcap_{k=150}^{200}A_k$, compare with the exact values, and explain what happens as the window moves off to infinity.

#### Hint
For the inverse, strip factors of 2. For (b), use NumPy's `max` and `min` along each row of a 0–1 array.

#### Solution
```python
import numpy as np

def pi(m, n):
    return 2**(m - 1) * (2*n - 1)

def pi_inv(k):
    a = 0
    while k % 2 == 0:
        k //= 2
        a += 1
    return a + 1, (k + 1) // 2

# (a) every k <= 1000 is hit exactly once (m <= 10 and n <= 500 suffice)
hits = {}
for m in range(1, 11):
    for n in range(1, 501):
        k = pi(m, n)
        if k <= 1000:
            hits[k] = hits.get(k, 0) + 1
assert sorted(hits) == list(range(1, 1001)) and set(hits.values()) == {1}
assert all(pi(*pi_inv(k)) == k for k in range(1, 1001))

# (b) union and intersection over tosses 150..200 (51 tosses)
rng = np.random.default_rng(0)
X = rng.integers(0, 2, size=(10_000, 200))   # column k-1 is toss k, 1 = heads
win = X[:, 149:200]
print("union        ~", (win.max(axis=1) == 1).mean(), " exact", 1 - 2.0**-51)
print("intersection ~", (win.min(axis=1) == 1).mean(), " exact", 2.0**-51)
```
The union comes out as 1.0 and the intersection as 0.0, matching $1-2^{-51}$ and $2^{-51}$ to the precision 10,000 runs can show.

As the window $[n,\infty)$ moves out, $P\big(\bigcup_{k\ge n}A_k\big)=1$ for every $n$, so $P(\limsup_nA_n)=1$: heads occurs infinitely often. And $P\big(\bigcap_{k\ge n}A_k\big)=0$ for every $n$, so $P(\liminf_nA_n)=0$. Passing to the limit uses continuity of probability, which Module 1.2 proves; the second Borel–Cantelli lemma gives the first fact directly.

### T1
At the stand, taxis and passengers are matched instantly, so taxis and passengers never wait at the same time. A state is a pair $(k,q)$: $k\in\{0,\dots,K\}$ taxis waiting and $q\in\{0,1,2,\dots\}$ passengers waiting, with $kq=0$. Let $S$ be the set of such pairs. Prove that $\varphi(k,q)=q-k$ is a bijection from $S$ onto $\{z\in\mathbb Z:z\ge-K\}$, and conclude that $S$ is countably infinite.

#### Hint
Check that $\varphi$ is well defined, injective and surjective separately. The condition $kq=0$ does all the work: split by the sign of $z=q-k$.

#### Solution
**Well defined.** $q-k\ge-k\ge-K$, so $\varphi$ lands in the target set.

**Injective.** Let $z=\varphi(k,q)$ for some $(k,q)\in S$. If $z>0$, then $q>k\ge0$, so $q>0$, hence $k=0$ (because $kq=0$) and $q=z$. If $z<0$, then $k>q\ge0$, so $k>0$, hence $q=0$ and $k=-z$. If $z=0$, then $q=k$ and $kq=k^2=0$, so $k=q=0$. In every case $(k,q)$ is determined by $z$, so two states with the same $z$ are equal.

**Surjective.** For $z\ge0$ take $(0,z)\in S$. For $-K\le z<0$ take $(-z,0)\in S$.

The target $\{-K,-K+1,\dots\}$ is countably infinite (shift it by $K+1$ to get $\mathbb N$), so $S$ is too.

This relabelling turns the two-sided taxi stand into a single line of states, $\dots$, 2 taxis waiting, 1 taxi waiting, empty, 1 passenger waiting, $\dots$ So the stand is a birth–death chain on $\{-K,-K+1,\dots\}$. In Module 0.3 you will write its generator matrix.
